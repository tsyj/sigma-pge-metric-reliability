# PREREG_E44 — 内潮环境判据可靠性检验（预注册）

写于 2026-09-02 03:2x（13 条 run 已发射、尚无任何 case 完成分析；本文档在收数脚本
analyze_e44.py 首次对新 case 运行之前盖章。在档 pf 三臂 / 500 km 锚的既有数字
（PHASEFIX_TABLE.md、BANDTOLL_VERDICT.json）在写作时已知，预测不涉及复述它们。）

## 1. 三个问题
Q-A 风驱环境穷举冠军 uv_ratio = rms(u_末帧)/mean|v_末帧|（env2.py:303 逐字），在内潮环境还抗刷分吗？
Q-B 内潮环境里存不存在"既反映数值误差、又不毁物理信号"的可见判据？
Q-C "让一切变小"与"构造性失效"两类刷分通道，在内潮环境的可见指标组上如何显形？

## 2. 扫描矩阵（13 条新 run，全部 phasefix 口径 84 km/13 层/10 d）
A 组 修正臂+VISC4 ∈ {3e6,1e7,3e7,1e8,3e8}；A' 组 dj+VISC4=3e8
B 组 combo 换 B 样条节点距 m ∈ {2,3,6}（γ=7.29e-4；在档 pf_combo=m4 补位）
C 组 combo m=4 换 γ ∈ {1.8225e-4, 2.916e-3, 1.1664e-2}
D 组 平底 dj（ini ocean_time +15330 与全体同口径）

## 3. 预测（先于收数）
P1 A 组：deep_dc_rms 随 VISC4 单调下降（"变小"通道在内潮侧同样敞开）；
   但守门指标 bt_M2_amp（正压 M2 振幅）在 VISC4≥1e8 时显著下降（>2% 相对 pf_v4）——
   "变小"刷分会连正压潮一起压，这是内潮侧特有的暴露面。
P2 B 组：spec_tail_frac 随 m 增大单调下降（B 样条按波长设计，构造性必然）；
   deep_dc_rms 对 m 变化平缓（<30% 相对变化）——即"残差流"类代理**排不出**
   500 km 锚已证实的第二模损伤序（m2 轻 → m6 重）。
P3 uv_ratio：预测在内潮环境**失效**。理由：M2 体强迫是纬向的，真潮流本身
   u≫v（强各向异性），rms(u)/mean|v| 主要度量真信号极化而非伪流各向异性；
   预测它在 A/B/C 组间的变化方向与任何物理损伤序都不一致（无单调对应）。
   ——若成立，这是设计原则(3)"无量纲不变量"的**边界条件**：不变量必须
   相对"真信号的对称性"选取，真信号各向同性时 u/v 比才有意义。
P4 D 组平底：Pnet_MW ≈ 0（|Pnet| < 0.05 MW，即海山臂的 ~1%）——零通道①成立。
P5 C 组 γ=1.1664e-2（超在档范围 1.6 倍）：模式仍稳（算子谱∈[0,1] 无条件稳定），
   但斜压 M2 振幅整体显著压低；若 RC≠0 则如实记录。
P6 A' dj+3e8：deep_dc_rms 相对 pf_dj 大幅下降（无修正猛拧黏性也能"变好看"）——
   风驱侧"荒谬旋钮"通道的内潮版。

## 4. 判据（什么算"可见判据在内潮环境可信"）
C1 对 B 组按物理损伤排序（500 km 锚：m2 轻→m6 重）方向一致（Spearman ρ>0.8）；
C2 对 A 组"变小"通道有抵抗：不把 VISC4=3e8 排为最优；
C3 平底读数落在零通道预期内。
候选：deep450_m2_frac（深水 N<ω 占比）、bt_M2_amp 偏离、spec_tail_frac、
deep_dc_rms、uv_ratio。逐一按 C1–C3 打分，结果如实并报（含全败情形）。
