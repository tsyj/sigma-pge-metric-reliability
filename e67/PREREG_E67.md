# E67 预注册：E66 的「配方」选出来的尺子，换强迫方向还站得住吗

**登记时间**：2026-09-05 凌晨，在 E66 结果之后、本实验运行之前。

## 背景
- E57：纬向风上两关同过 **204** 把；换到经向再筛剩 **88** 把（独立期望 5.4，富集 16.3 倍）。
- E65：「排得准」在本环境里几乎等价于「跟着伪流大小走」（ρ=+0.976），而那正是最可刷的一类（ρ=−0.661）。
- E66：把「只是跟着伪流走」那部分共同成分扣掉之后，两关冲突从 −0.674 缓解到 **−0.478**，
  同过者从 204 涨到 **444**，且**全部是比值型（尺度不变）**。

**于是给出一个可检验的配方**：好尺子 = 比值型（尺度不变）+ 携带超出伪流幅度的信息（A⊥ 高）+ 抗糊弄（B 高）。
本实验问：**按这个配方在纬向风上选出来的那批，换到经向风、45° 风上，存活率是不是比原口径高？**

## 两个候选集（都在纬向风上选定，之后不再调整）
- **S_A**　= { A ≥ 0.7 且 B ≥ 0.9 }　（原口径，E57 的 204 把）
- **S_A⊥** = { A⊥ ≥ 0.7 且 B ≥ 0.9 }　（新配方，E66 的 444 把）

## 换向后的判据（与纬向逐字相同，不为新集合放宽）
在经向风、45° 风上各自重算 A 与 B，仍要求 **A ≥ 0.7 且 B ≥ 0.9** 才算「站得住」。
（注意：换向后一律用**原口径 A**，不用 A⊥——否则等于用同一个技巧在两边都开后门。）

## 预注册的四条预测
- **P1**：S_A⊥ 的跨向存活**率**（存活数 ÷ 集合大小）**高于** S_A。
  这是配方的核心主张：扣掉伪流代理这一步，让筛选更能跨场景搬运。
- **P2**：两个集合的存活数都显著高于各自的独立期望（富集 ≥ 2 倍）。
- **P3**：跨向存活者**全部是比值型**，一个绝对量型都没有。
- **P4**：三向同时站得住（纬向∩经向∩45°）的数目，**S_A⊥ 严格大于 S_A**。
  已知 S_A 侧的三重交集在原报告里是 0（且与随机期望 0.71 无差别）。
  若 S_A⊥ 侧仍是 0，则本配方**未能**解决跨向不可迁移问题——这条要如实报出来。

## 判读规则
- 独立期望按各方向上 P(A≥0.7)×P(B≥0.9)×|集合| 计。
- 任何一条被推翻都如实记录，不改预测、不改口径。
- **若 P1 被推翻（新配方还不如原口径），必须原样报出**，不得因为它推翻了 E66 的推论而弱化。
- 本实验不进已封存的报告；作答辩问答弹药与后续研究起点。
