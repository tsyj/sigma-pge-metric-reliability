## 为什么这些档足以排除「偶然」

1. **零模型基率**给出「随便一个候选也能通过」的概率（风驱 1.33%、内潮三轴 13.1%）——单环境单调是低门槛，这一条直接压低了我们自己结果的分量。
2. **交集的独立随机期望**给出交集计数在零假设下的分布：三重交集 0 与期望 0.71 无差别（P0=0.49），因此「0」本身不是证据；真正的信号是纬向∩经向富集 16 倍、两处与内潮的交集贫化。
3. **正对照（第 08 档）**证明协议不是在杀一切：把隐藏真值自己当尺子走一遍九项审计，按定义或实测全过。
4. **BH93（第 07 档）**把社区公认的那把尺子也放进同一张判读表，避免「只审我们自选的四把」。
5. **随机与 LLM 基线**给出同预算下「乱猜」与「有目标的 Agent」的对照：2/3 席随机掉得比 Agent 更深，说明陷阱是目标函数的属性而非 Agent 的愚蠢。
