# PREREG_E60 — 抗刷率 B 本身是不是地形陡度的函数（先盖章，后跑）
写于 2026-09-03（本地 +08:00，无第三方时间戳）。

## 动机
本作品用两关判据杀尺子：排序力 A 与抗刷率 B。E59 已把预测器自己审了一遍（发现它在极端处失效）。
本实验审的是**判据本身**：B 的定义是「同参数换到误差恒为零的平底，读数不变好看」——
但"平底 vs 海山"这个配对里，海山有多陡是一个自由参数。若 B 随陡度剧烈变化，则
**"抗刷"就不是尺子的固有性质，而是测试条件的函数**，与我们批评那些代理指标的毛病同型。
报告 §4.7 已把"陡度 rx0 未变"列为适用边界；本实验正面检验它。

## 设定
- 陡度轴：现成网格 rx0 ∈ {0.200, 0.441, 0.599, 0.694}（42×42×13，`pge_grid_rx0*.nc` + `pge_ini_rx0*.nc`），
  外加已有的 r26steep（48×48，rx0=0.766）作参照，但**跨尺寸不并入同一统计**。
- 每个 rx0 配一个同尺寸、同最大深度的平底对照（h≡max(h)，初值按 T=f(z) 逐点生成，同 E56 做法）。
- 旋钮：VISC2 七档 {0,50,150,400,800,1500,2747}，与 E56/初赛逐字相同；其余参数不动，风驱强迫同纬向风。
- 对每个 rx0：用与 E40 逐字相同的穷举器算全部候选比值的抗刷率 B（**只需配对，不需要 MITgcm 真值**）。
- 主指标：不同 rx0 之间「B≥0.9 的候选集合」的 Jaccard 相似度；副指标：B 的秩相关。

## 预测（先写死）
- P1：任意两档 rx0 之间，B≥0.9 集合的 Jaccard **< 0.5** —— 即抗刷性显著依赖陡度。
- P2：已知完全不抗刷的 deep_rms_800 类在**所有**陡度上 B ≤ 0.1（这是零真值通道的构造性结果，应当稳健）。
- P3：B 的候选间秩相关在相邻陡度档之间 ρ > 0.7（即整体排序稳定，只是阈值附近抖动）。
- P4：平底臂在所有 rx0 上的伪流 max|u| 与陡海山臂之比 < 0.1（配对有效性自检）。

## 判读
- 若 P1 成立而 P3 也成立 → 结论是"**B 的排序稳健、但阈值附近的集合成员不稳健**"，据此把 §4.7 的边界从"未验证"升级为"已量化"。
- 若 P1 不成立（Jaccard ≥ 0.5）→ 结论是"**抗刷性在本环境族内对陡度稳健**"，这对本协议是正面结果，照写。
- 若 P2 不成立 → 说明零真值通道的构造性结论在某些陡度上失效，属重大发现，必须单独报告。
- 跨尺寸（42×42 vs 48×48）的比较只作定性参考，不进主统计。
