# PREREG_E59 — 无真值特征能否预测排序力（先盖章，后跑）
写于 2026-09-03（本地 +08:00，无第三方时间戳）。

## 动机
本作品此前的判据是两关：排序力 A（= −ρ，与隐藏真值的秩相关）与抗刷率 B（同参数换平底不变好看）。
**A 需要真值，B 不需要。** 现实中真值往往拿不到，因此只有 B 一类可执行。
已测得 ρ(A,B) = −0.674：无真值的 B 携带关于 A 的信息，只是方向为负。
本实验问：**只用不需要真值的观测，能否预测一把尺子有没有排序力？** 若能，则本协议从"只能判死"变为"可在无真值处筛选"。

## 设定
- 候选空间：风驱环境全比值空间（124 基元 → 15376 候选），与 E40/E57 逐字相同。
- **训练集 = 纬向风环境；测试集 = 经向风环境。**跨环境泛化是唯一验收方式；不做同环境交叉验证充数。
- 目标变量 y = A ≥ 0.7（沿用初赛阈值，不调）。
- 特征（**全部不得使用 skill_vs_zero 或任何真值配对**）：
  f1 = 配对抗刷率 B（平底 vs 海山，同参数）
  f2 = 平底臂上的相对离散度 IQR/|中位数|（零真值通道的噪声水平）
  f3 = 陡海山臂上的相对离散度（信号动态范围）
  f4 = 平底中位数 / 海山中位数（地形敏感度；≈1 表示对地形不敏感）
  f5 = 分子与分母是否同一物理分量（u/u、v/v… 为 1，异分量为 0）
  f6 = 分子与分母的深度层级差（表层 s50/s200 与深层 d400/d800/d1500 的层级编号之差）
  f7 = 候选值在海山臂上的单调性代理：与旋钮 VISC2 的秩相关（旋钮已知，不需真值）
- 模型：只用**逻辑回归**（无正则调参、无特征选择、无超参搜索），系数在训练集上一次拟合。
- 主指标：测试集（经向）上的 **AUC**；副指标：按预测分排序取 top-204（与实际通过数同量）时的命中率（precision@204）与其相对随机基率的提升倍数。

## 预测（先写死）
- P1：单特征 f1（抗刷率）在测试集上 AUC **显著偏离 0.5**（即 |AUC−0.5| > 0.05），方向为**负向预测**（B 越高越不可能有排序力）。
- P2：七特征逻辑回归在测试集上 AUC ≥ **0.70**。
- P3：precision@204 至少是随机基率（407/15376 = 2.65%）的 **3 倍**。
- P4：f2（平底噪声）单独也有预测力（|AUC−0.5| > 0.05）——因为在按构造零真值的通道上噪声大的候选，其在真环境上的读数也更可能是噪声主导。

## 判读与如实申报
- 若 P2 不成立（AUC < 0.70），则结论写成"**无真值特征对排序力的预测力有限**"，并给出实测 AUC，不修饰。
- 若 AUC 显著 < 0.5（反向预测），照写，并说明这仍是可用信息（取反即可）。
- 不做任何事后特征增删；若代码有 bug 需重跑，重跑记录与作废件一并存档。
- 本实验**不能**证明该预测器可迁移到本环境族之外（同海山、同网格、同代码），此边界写进报告。
