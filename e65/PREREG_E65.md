# E65 预注册：「减伪流」与「保真流」在指标层面是不是同一件事

**登记时间**：2026-09-04 深夜（答辩前）
**动机**：本作品的主线是「谁来给尺子打分」。物理侧的主线问题是：σ 坐标要减伪流，
但**不能只减伪流**——只盯着「伪流变小」这一个读数，有把真流一起压掉的风险，所以必须同时保真流。
本实验把这句话在指标层面做成可测的命题。

## 定义（全部在已有的 15376 个候选读数上算，不重跑任何算例）
对每个候选读数 m：
- **A(m) = −ρ(m, 隐藏技巧评分)** —— 「保真流」的操作化：它的名次跟真值对不对得上。（沿用 E57）
- **B(m) = 配对抗糊弄率** —— 换到平底后读数不许凭空变好看。（沿用 E57）
- **D(m) = ρ(m, 伪流幅度)** —— 新增：这个读数在多大程度上**只是伪流大小的代理**。
  伪流幅度取陡海山臂上同一批算例的全域流速均方根（`base_quantities` 的既有底量），不新造统计量。
- **G(m) = 尺度敏感度** —— 新增：把整个场按常数因子缩放，读数跟着变多少。
  比值型读数分子分母同缩，恒为 0；绝对量型读数为 1。用解析判定，不做数值扰动。

## 预注册的四条预测（结果出来之前写死）
- **P1**：ρ(D, A) < 0 —— 越是「跟着伪流走」的读数，越排不准真值。
  这是「只减伪流会误杀真流」在指标层面的直接表述。
- **P2**：ρ(D, B) > 0 —— 跟着伪流走的读数，反而更容易通过抗糊弄关
  （因为平底上伪流本就为零，它跟着变小是"正确"的）。若 P1 与 P2 同时成立，
  说明**抗糊弄关本身会奖励「跟着伪流走」，而那恰恰是排不准的那一类**——这是两关互斥的一个机理解释。
- **P3**：绝对量型读数（G=1）的 B 显著低于比值型（G=0）。
  即「抗糊弄」这一关主要在惩罚绝对量。若被推翻，说明 B 不是简单的量纲效应。
- **P4**：在 A≥0.7 且 B≥0.9 的那 204 个候选里，D 的分布显著低于全体。
  即两关同过的那批，恰恰是**不跟着伪流走**的那批。

## 判读规则
- 相关系数一律用 Spearman；显著性用置换检验（n=2000，固定种子 0）。
- 任何一条预测被推翻都如实记录，不改预测、不改口径。
- 本实验不进主报告（报告已封存），只作答辩问答弹药与后续研究的起点。

# 结果与如实记录（2026-09-05 凌晨，实验完成后追加，预注册正文未改）

**四条预测中三条被推翻，且推翻的方向本身给出了机理。**

| 预测 | 实测 | 判读 |
|---|---|---|
| P1 ρ(D,A) < 0 | **+0.9762**（p=0.0005） | **推翻**。方向完全相反 |
| P2 ρ(D,B) > 0 | **−0.6610**（p=0.0005） | **推翻**。方向完全相反 |
| P3 绝对量 B < 比值型 B | 0.138 vs 0.501 | 命中 |
| P4 两关同过的 D 低于全体 | 0.801 vs 0.007 | **推翻**。恰恰相反，同过的那批 D 很高 |

**这三条推翻合起来给出一个统一解释**：
在这个环境里，隐藏的真值技巧评分本身主要由伪流幅度决定。于是
- **A ≈ D**（0.976）：「排得准」几乎等价于「跟着伪流大小走」；
- **D 与 B 反号**（−0.661）：而「跟着伪流走」正是最容易被糊弄的一类——
  换到平底，伪流按构造为零，这类读数自动变好看。
- 两者合起来直接推出 **ρ(A,B) = −0.674**，与 E57 独立算得的值逐位一致。

**⇒ 两关互斥不是一个神秘现象，它几乎完全由 D 这一条轴解释掉：**
**真值信号本身被伪流幅度主导 ⇒ 排得准的尺子必然是伪流的代理 ⇒ 伪流代理天生可刷。**

**必须写明的限制（防止过度宣称）**：
A ≈ D 有相当一部分是**构造性的**——真值技巧的定义里本就含误差幅度，而伪流是误差的主要成分。
所以这条结果的价值不在于「发现 A 和 D 相关」，而在于**给出了互斥的定量分解**：
互斥的量级（−0.674）几乎全部来自 D 与 B 的反号（−0.661），残差很小。
P4 被推翻还说明：两关同过的那 204 个**并不是靠脱离伪流做到的**，而是靠尺度不变（比值型），
这与 P3 命中相互印证。
