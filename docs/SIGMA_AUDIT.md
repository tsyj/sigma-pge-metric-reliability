# 离线送检台

`python -m sigma_audit submit 'u|s50|mean_abs / v|s50|rms'` 从既有缓存计算判定行，不运行物理求解器。表达式支持单个基元或两个基元之比；`keys` 列出基元，`replay` 只读回放 E61 存档。

`selftest` 核对参照解正对照、BH93 诊断代理量在风驱账本上的点值，以及三环境全空间计数。它不把静止海幅度检验本身重新定义为技巧评分。排序沿用原实现的序数秩；并列值的平均秩稳健性不在本版验证范围内。

数值依赖固定 NumPy 2.0.2。NumPy 1.26.4 的默认排序在并列值处给出了不同序数秩，实测使 E65 点值对账及 45° 计数失败；不能放宽测试或改冻结答案来通过。换依赖版本需另作数值兼容性核验。

## 公开快照与原始封存门

代码来自 `e71_innov/oss_audit_kit/sigma_audit` 的收尾版。本次只移植路径、包资源、输出位置及展示文字，数值轴和阈值保留。缓存、E65 登记轴及 E67b 登记值按原字节复制，来源哈希在 `sigma_audit/data/RELEASE_MANIFEST.json`。

Git 不记录文件的 444 权限。公开包使用 `release_snapshot` 模式核对封条格式、日期格式、正文哈希及全部缓存字节；这只能发现相对于随包清单的改动，不能抵御清单与正文协同修改，不能证明历史封存时间。原始 `check_seal` 的 G1–G6（含只读权限）检查仍保留，并接受故障注入测试；公开版不开放缓存重建，避免用回放校验代替研究阶段的留出门。

参照解由另一套代码计算，不等于真实海洋观测。平底臂缺参照误差时记为不可测。两道阈值通过只适用于本环境族，不是统计覆盖率保证。历史交集为空不构成泛化不可能性证据。

## 验证入口

`nice -n 19 bash scripts/ci.sh` 顺序运行 selftest、smoke、原有送检故障注入、端到端测试及快照破坏测试，日志写入 `ci-logs/`。GitHub Actions 使用相同入口；本地通过不等于托管 CI 已运行。

Python 插件入口会执行用户提供的 Python 文件，只应用于自己信任的代码。表达式送检无需插件文件。公开缓存不包含外部报告或论文的原始数据。
