# 3 分钟答辩脚本（约 430 字，语速 2.4 字/秒 ≈ 180 秒）

【0:00–0:20 一句话】我们研究的不是怎么治 σ 坐标伪流，是"谁来给尺子打分"。结论一句话：尺子的可靠性不是标量的性质，是审计协议的性质。

【0:20–0:50 环境】我们把真值藏起来，Agent 只看得见读数。环境写成四元组：旋钮、可见读数、隐藏判分、审计算子。审计算子有八个——换平底、零真值通道、盒宽、时钟相位、盖章预测、第三种强迫、匿名换名、真值锚。每个算子回答一个问题，都留了机时成本和它杀掉了谁。

【0:50–1:40 主结果】这张 kill board 四把尺子、八列审计，没有一行全绿。第一行是我们自己论文的头条——"只保留 11.1% 的辐射"——只改盒宽它摆 7 倍，修一行时钟从 4.6 变 7.9，它量的是域共振，我们会更正论文。第四行是穷举出来的冠军 u/v 比值，两个环境都过，预注册赌它失效还被反驳了；但真值一锚、相位一扰、盒宽一换，它一路收窄；把风转 90 度，它死了，两环境交集的 13 把全部死了，三重交集是零。

【1:40–2:20 机理与 Agent】为什么没有普适尺子：排序力要真信号钉住一端，抗刷分要换平底不变好看；前者由强迫方向决定，后者由区域几何决定，纬向强迫下巧合重合，经向下分家。Agent 这边三个角色：当对手它交出波功率砍七成的方案、中性措辞也一样；当评审它信有名字的坏尺子、摘掉名字就翻对；当提议者它和随机没区别。它现在是对手和被试，不是发现者——这是我们写明的缺口。

【2:20–3:00 沉淀】88 条算例一次完赛、全部 md5 审计，一条预测被反驳、一次指标降格、一次论文更正，都在仓库里；kill board 一条命令重生成。这不是一个算例，是一套给尺子打分的协议——换你的模式、你的尺子，也能跑。谢谢。
