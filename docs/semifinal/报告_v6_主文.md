# 谁来给尺子打分：σ 坐标伪流环境中的代理指标可靠性探索
## 复赛《科学发现与环境定义报告》

> **古德哈特定律（Strathern 1997）说：当一个指标成为目标，它就不再是一个好指标。** 我们这项工作把这句话做成一个可运行的实例：在 σ 坐标海洋模式的伪流治理上，把真值藏起来，问一句"这些读数配不配当判据"。
> 一句话结论：**任何单个强迫下都能找到同时通过两关的候选（纬向风 204 个、经向风 407 个、内潮 2574 个），但没有一个候选能在换了强迫方向之后仍然通过**——而这两关在全部 15376 个候选上呈显著负相关（ρ = −0.67，两关同过 204 个 vs 独立期望 2159 个，贫化 10.6 倍），乌托邦角在实测 Pareto 前沿上为空。所以我们交的不是一把尺子，是一套给尺子打分的**审计协议**，并用它审了我们自己的隐藏判分，也审了我们自己论文的头条指标。
> 我们这项工作按官方说法属「**元环境 / 评测范式**」类（手册 05 节），并已按其门槛「以具体领域实例跑通」：σ 坐标伪流治理这一具体领域问题、207 条真跑算例、九项审计算子。
> 附录 A 为初赛定稿正文；附录 B 为实验编号 E40–E62 全表与数字出处；附录 C 为下一步的对抗式双 Agent 环境规格；附录 D 为正文为控制篇幅移出的实验细节、预注册逐条核对与官方自检自答（各节标题标明对应正文位置）。全部数字的单一真源是仓库 `e44_tide/analysis/`、`e52/`、`e55/`、`e56/` 下的 JSON，`bash scripts/reproduce_core.sh` 一键重算。

# 第一问 · 科学问题与发现目标

## 1.1 问题（初赛定稿，原文见附录 A）

σ（地形跟随）坐标海洋模式在陡地形上会凭空长出伪流。初赛用独立求解器量化过：同一座海山、同样的风，第 1 天结束时全域最大流速，MITgcm z 坐标真值 **9.24 cm/s**，ROMS σ 坐标 **99.53 cm/s**（此处是**全域最大流速**，与文献中常报的深层平均量不是同一统计量；出处见附录 D-1.1）。真正的问题在后一层：评价"伪流治理好不好"的每一个可见读数——深层流速、残余流、辐射功率——本身都是一把候选**尺子**（proxy metric），而真值平时拿不到。

## 1.2 这个问题不是我们提的

代理指标不可信在多个领域已被独立记录（ERBench、Kosmos、GEM、ClimAgent、CMIP-Forge；数值海洋学侧 Mellor 等 1998、Shchepetkin & McWilliams 2003、Schifano 等 2025；逐条对照见附录 D-1.2，文献编号见附录 B）。**但处理方式都是事后个案更正；据我们检索（Crossref 与 arXiv，2026-09-02）未见有工作把它做成一套可复算的失效判定程序：对全部候选一视同仁，且把作者自己的头条指标也放进去。**这是我们切入的位置——"据我们检索未见"是一个检索结论，不是优先权主张。

## 1.3 为什么必须让 AI 介入，边界在哪

1. **将来刷这些指标的主体就是 Agent**（CVEvolve 在开发集上把 F1 推到接近 1，而 holdout 第 5 轮见顶、第 9 轮后崩），"指标可不可信"从方法学问题变成了安全问题。
2. **穷举 + 配对反事实检验的规模，人做不了**：124/140 个基元标量构成的全比值空间（15376 / 19600 个候选）逐一计算排得准的程度与抗糊弄率，并在三个强迫方向上重算——三个风向合计 4.61 万次候选评估（15376×3），内潮环境另有 19600 次。
3. **Agent 本身就是尺子的使用者，也是污染源**：A7 显示同一份数据，把指标名字摘掉后大模型评审的两处误判全部翻转。

**边界**：我们这项工作不研究 Agent 算法（memory / harness 设计不在范围内，这也与出题人"算法研究不太在我们的 scope 内"的计算方式一致）；结论不外推到真实海洋观测。

## 1.4 我们希望 Agent 发现什么，以及核心声明

希望 Agent 发现的是一类**结构**：真值恒为零的子空间在哪里（一把好尺子应当量在那里）。E43 显示它做不到，缺口就精确落在这一步。核心声明分两句，先负后正：
- **负**：在本环境 124/140 基元的全比值空间内，任何单个强迫下都存在同时通过两关的候选，但**未发现**任何候选能在三个强迫方向下都通过；即便只看单个强迫，两关也是互斥的：同时通过的数量比两关独立时该有的少 10.6 倍（4.1）。这与 Skalse 等（2022，arXiv:2209.13085）定理 1 一致，多目标下要求九个冲突算子上的全支配点也近乎先验必然（arXiv:2604.09417）。**"全军覆没"是预期结果，不是发现。**
- **正**（均为检索结论，不主张优先权）：三样可检验的东西——(i) **正对照行**：把隐藏真值自己当尺子走一遍全部审计，按定义或实测全过，证明协议不是在杀一切；(ii) 每一格可追溯到一条审计、一个数、一个文件的**死因**；(iii) 两关的**双目标结构**被定量刻画（ρ(A,B) = −0.67，贫化 10.6 倍，Pareto 前沿五点，乌托邦角为空），并给出阈值敏感性曲面。（原文见附录 D-1.4）

环境写成四元组 **(K, V, H, A)**（图 1）。前三项初赛已有；复赛把 **A（审计算子集）列为环境定义的第四个正式组成部分**——这正是文献里空着的一格：EurekAgent 把环境工程正式命名并给出四维（权限/产物/预算/人在环），**没有审计维**。隔离与隐藏评测器本身是本领域现行做法（AEvo、CVEvolve 的 holdout、ERBench 的保密评测集），我们的 H 设计只能算**沿用**，不是新意；新意在 A，以及我们用 A 审了 H 自身。

## 2.2 H 的两级分级：哪一侧算真值，哪一侧只是判分锚

- **H_风驱 = 独立求解器真值**（MITgcm z 坐标，Mitigated 级）：外部操作、不同代码、不同垂向坐标，构成回路有效性的绑定条件。
- **H_内潮 = 自参照判分锚**（Weak 级）：500 km 大盒上"先提前登记的预测后验证"的逐垂向模态远场功率保留比，**同一求解器、同一套代码、只换盒宽**。**"真值"二字只留给风驱侧，内潮侧一律写"判分锚"**；所有依赖内潮锚的结论（A8、4.2 的门规则、4.3 的排得准的程度判定）继承 Weak 标签（措辞出处见附录 D-2.2）。
- 内潮侧另有独立求解器的一列可用但本轮未纳入判据（论文 v8 的 M2 孪生：深层残余流误差 11.916 → **7.842**、上层 4.615 → **2.407**，在这一侧治理是让残余流**更接近**真值的；见附录 D-2.2）。因此 4.2 中对重治理组的"陷阱"判定是**以单侧锚为条件**的判定，不是物理发现；双侧计算方式下它是一个 Pareto 权衡。
- 两者共用一条零真值通道：平底海上伪流按构造为零、内潮辐射恒为零。

各算子的机时成本与独立性来源两列见附录 D-2.3。**要说清楚一点**：九项审计**不等于九份独立证据**。A1/A2/A9 的独立性来自按定义就为零的对照，A6 来自新环境，A8 风驱侧来自独立求解器；而 **A3/A4/A7 没有外部独立性——它们只能证伪，不能认证**。因此这份报告中"存活"一律仅指"未被该算子证伪"，不构成任何外部认证；我们刻意不让回路闭合于自身，H 与 A 是回路之外的有效性条件（closure through the world 而非 closure on itself，arXiv:2605.26200）。

## 2.4 可比性契约与两处主动申报

所有读数只在同初值相位、同窗口、同一种计算方式内比较，跨相位用窗均值版。(1) 可见的环带功率在节点距轴上与隐藏模态损伤同序（ρ = −1.0）——它是环境里故意保留的一个**陷阱配置**：可见读数会变好看，隐藏判分却在恶化。(2) 三个风向环境共用同一座海山、网格与代码，只换强迫方向与真值；ROMS 区域 x 周期、y 陆墙，转 90° 后 ROMS 侧**不是**镜像（表层 u/v rms 4.32/9.93 → 9.93/6.63），MITgcm 真值侧是精确镜像——这既是 4.3 机理的来源，也是它的边界。

# 第三问 · Agent 如何完成发现

## 3.1 工作流：verifier-driven，不是提示词驱动

预注册（sha256 + 文件系统时间戳，**无第三方时间戳服务**；算例时刻记录方式见附录 D-2.1）→ 扫描 → 逐条对账 → 审计。规则活在会大声失败的确定性脚本里：输入件 md5、白名单差分、配置回显自检、健康门、`smoke_test.sh`（5/5）、`reproduce_core.sh`。**三件必须申报的事**：① 内潮第一批 13 条为事先登记的实验组，其后 7 组后加的采样是看到首批结果后追加的，p 值同时给两种计算方式（4.4）；② E52 转风**未预注册**——先验假设写于 `STATE_BRIEF.md`（发射前 20 分钟），判据脚本与阈值与纬向逐字相同，无可调自由度；③ E55（45° 风）与 E56（BH93）**已预注册**（sha256 `ec1b1ecf…` / `7792b30e…`）。

## 3.2 一次完整的探索循环

陷阱局六轮 = 一次完整循环：观察（可见读数）→ 行动（提交配置）→ 环境真跑其下单的三条算例 → 反馈（读数 + 健康门）→ 判断 → 记录（JSONL）。同预算随机基线三席（种子 0/1/2）构成"乱猜"对照。

## 3.3 Agent 的三个角色（详细叙述与先行工作对照见附录 D-3.3）

**对手（陷阱局）**：目标"把深层残余流降到最低"。终选 `ag_s3`：深层残余流 3.25（对未做任何治理的那组 6.08 为 −47%），环带功率 4.15 MW（对固定参考态修正的那组 14.08 为 30%），可见 u/v 从 2.54 升到 3.46 一路报警，它没有用；同预算随机基线两席掉进 γ×16（功率 −8.9 MW）。**一个守规矩的 agent 被一个看起来完全合理的读数带到了波功率只剩 30% 的方案**。

**评审（判据局 / 换名局）**：真名 / 匿名（M1–M7）/ 互换名三组配对，把"名字"隔离为因果通道。真名版把环带功率标可信 3/5、把 u/v 标可刷 4/5；匿名版降到 1/5 与 1/5；互换名后穿着"环带功率"外衣的 u/v 数据仍被疑 4/5；阴性对照残余流两版都被标可刷 5/5——病症的学名是 **authority borrowing**。跨模型复核（E62，`deepseek-v4-flash`，每条件 n=5）：环带功率 3/5→1/5 两个模型完全一致，但真名下 u/v 被判可刷 pro 4/5、flash 只有 2/5——可主张的只有**"有名字的头条指标更容易被信任"在两个模型上都成立**。

**提议者（E43，初赛）**：30 轮（20 轮格式有效）0 通过；按穷举基率 1.33%，20 抽 0 中的概率 0.77——与随机无差别；缺口具体到"构造零真值子空间"这一步，4.8 进一步把它定位到"稳定性而非能力"。

# 第四问 · 发现结果与验证

**参照系**（十种，独立交付件 `baselines/BASELINES.md`，`bash baselines/run_baselines.sh` 重算）：恒零模型 / 无干预组 / 平凡解（单调加黏性）/ 随机搜索三席 / 零模型基率 / 交集的独立随机期望 / 穷举器 / BH93 社区标准检验 / **隐藏真值自身（正对照）** / LLM 三种措辞。

## 4.1 两关互斥：我们这项工作的定量支柱

排得准的程度 A（= −ρ，与隐藏真值的秩相关取反）与抗糊弄率 B（同参数换平底不变好看的比例）在全候选空间上 **Spearman = −0.674**。**全文凡写"排得准的程度 A"一律取 A = −ρ，正值为好；括号里另给的 ρ 才是原始秩相关。**（注意：这个 A 与环境四元组 (K, V, H, A) 里的审计算子集 A、以及附录 A 无关；抗糊弄率 B 也与 B 样条无关。）若两者独立，同时过关应有 **2159** 个候选（0.3155 × 0.4451 × 15376）；实测 **204** 个，**贫化 10.6 倍**。Pareto 前沿只有 5 点，从 (A=0.998, B=0.094) 一路走到 (A=0.948, B=1.000)，**乌托邦角 (1,1) 在实测前沿上为空**。阈值从 (0.5, 0.7) 扫到 (0.9, 1.0)，通过数 739 → 9，**没有任何阈值组合能让这个结构消失**。

**但必须同时申报这个结构的统计边界**：把抗糊弄率的点估计换成 Wilson 置信区间后判定要三值化，跨过阈值一律判 **U（未判定）**。u/v 在纬向风下 **32/32 满分，CI 仍是 [0.893, 1.000]，只能判 U**；经向 25/28 也是 U；而 45° 的 7/28、v/u 纬向 7/32、v/u 经向 3/28 三处**都是确定的死**。换句话说：**这套协议能可靠地判定一把尺子失效，却不能可靠地确认它有效**——n=32 的配对样本量下，即使满分也够不着 0.9 的置信下界；这份报告所有"通过"都应读作"未被证伪"（`E58_TRIVALENT.json`；全文见附录 D-4.1）。

这给了"排序与抗糊弄分了家"一个标准表述：两者是**冲突的双目标**，压成一个标量会因量纲缩放而失真（arXiv:2508.18170）。前沿上的 knee（A=0.948、B=1.000）在风驱环境上两关全过，**却不在跨内潮的 13 个交集里**——单环境的"接近完美"换个环境就死。

## 4.2 我们用这套办法先检验了自己的论文，并主动提出更正

环带"相干辐射功率"上过我们论文的头条："最优方案只保留 11.1% 的相干辐射"（84 km 盒：B 样条修正的那组 2.406 MW / MITgcm 21.643 MW）。**论文 v8 自己已做过五路相干通量审计并明写 B 样条修正的那组"fails all five"，论文先说了**（原文见附录 D-4.2）。
我们的增量精确地只有三条：**A3** 只改盒宽，它摆 7.24 倍而正压响应只差 1.5%；**A4** 修一行初值时钟，4.58 变 7.89 MW；换到 500 km 更干净的计算方式，B 样条修正的那组对 未做治理的那组的功率比从 84 km 的 0.525（2.406/4.583）回到 0.942（91.55/97.20）。由此判定：**它量的是域共振，不是辐射**。这份报告把它降为环境内只作展示、不参与任何判定的读数；论文将在定稿前作相应修订。该论文尚未见刊，因此本节引用的是其手稿数字，读者暂无法独立核对，此处照实标出来。
这是 ScientistOne 记录的 **Case 1 型失效**（自造内部指标当基准分报出、内部完全自洽、只看叙事的评审查不出）在人类作者身上的一次同型实例（其他领域的同型先例见附录 D-4.2）。

## 4.3 A9：把社区标准的那把尺子也放进同一张表（E56，预注册在先）

Beckmann & Haidvogel（1993）静止态海山检验是本领域的社区标准（真值解析为零）；我们按其设置跑 VISC2 七种 × 两地形 = 14 条（预注册 `7792b30e…`，P1/P2 命中、**P3 被反驳**）。**平底全档 `u_max = 0.0000`**；陡海山 `u_max` 从 99.72 单调降到 18.79 cm/s（降 81%）；**A1 配对抗糊弄 = 0.000**，社区标准的那把尺子同样完全不抗糊弄；P3 被反驳——同样的黏性档位在风驱算例上技巧评分反而单调**上升**（−8.48 → −1.46）。所以 BH93 尺子的毛病**不是"被糊弄过去"，而是"无判别力"**：它把伪流降 81% 报成改进，而真值说技巧评分**全程为负**，可见代理降 83% 而真实误差只降 49%，**夸大 1.69 倍**。详细设计、预注册原文与逐条核对见附录 D-4.5。

## 4.4 从判定失效到事先预测：不用真值能不能预测排得准的程度（E59，预注册）

排得准的程度 A 需要真值才能算，而真值在现实中往往拿不到；既然 ρ(A,B) = −0.674，无真值的 B 就携带着关于 A 的信息。预注册（sha256 `533c3062…`）：**纬向风环境训练、经向风环境测试**，七个无真值特征、一次拟合的简单线性模型。**结果（P1/P2/P4 命中，P3 未命中）**：七特征简单线性模型在**从未参与训练的经向风环境**上 AUC = **0.871**（单特征抗糊弄率 B 的 AUC = **0.2005**，方向为负，与 4.1 的互斥结构一致）；但 P3 未命中——precision@204 = 0.0882，**低于**基率 0.280，真正的结构是**非单调**：命中率从 0.037 升到峰值 **0.8306**，最高分一箱回落到 **0.6906**，最极端的 0.5%（77 个）跌到 **0.052**（图 4）。**这是我们这项工作的主题在我们自己的工具上复现了一次**——可操作的读法是**用中段，不要用顶端**；方向仍需真值确认。详细设计、预注册原文与逐条核对见附录 D-4.6。

## 4.5 抗糊弄率本身是不是地形陡度的函数（E60，预注册）

若抗糊弄率 B 随海山陡度大幅漂移，它和被它审判的代理指标就是同一个毛病。预注册（sha256 `af8fe044…`）：四种陡度 rx0 = 0.200 / 0.441 / 0.599 / 0.694，VISC2 七种 × 2 地形 × 4 陡度 = **56 条算例，全部完赛**。**结果（P2/P3 命中，P1/P4 未命中）**：**P1 被推翻，而且是朝有利方向**——我们赌两种陡度间「B≥0.9 的候选集合」的 Jaccard < 0.5，实测 **0.817–0.968**，**抗糊弄率在陡度轴上是稳健的**；P2 命中：深层残余流类在全部四种陡度上 B = **0.000**；P4 未命中是我们预注册时写错了前提，照实记下来。由此揭示两关的**不对称**（图 5）：同一把 u/v 换强迫方向排得准的程度 A 是 0.92 → 0.97 → **−0.17**（变号），而抗糊弄率 B 换地形陡度纹丝不动（Jaccard 0.82–0.97）——**B 测的是尺子自身的结构性质，A 测的是尺子与特定物理场景的匹配度**，这给"为什么必须同时要求两关"提供了正当性论证。**边界**：只在 42×42 的四种陡度内成立，与主环境 48×48（rx0=0.766）不并入同一统计。详细设计、预注册原文与逐条核对见附录 D-4.7。
