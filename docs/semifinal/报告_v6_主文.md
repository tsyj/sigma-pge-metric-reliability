## 复赛《科学发现与环境定义报告》 v6

> **古德哈特定律（Strathern 1997）说：当一个指标成为目标，它就不再是一个好指标。** 本作品把这句话做成一个可运行的实例：在 σ 坐标海洋模式的伪流治理上，把真值藏起来，问一句"这些读数配不配当判据"。

# 第一问 · 科学问题与发现目标

## 1.1 问题（初赛定稿，原文见附录 A）

σ（地形跟随）坐标海洋模式在陡地形上会凭空长出伪流。初赛用独立求解器量化过：同一座海山、同样的风，第 1 天结束时全域最大流速，MITgcm z 坐标真值 **9.24 cm/s**，ROMS σ 坐标 **99.53 cm/s**（`ledger/headline_table.json`，run `e2_7fc7950d63bc`，真值目录 `truth/sw_viscAz_1pEm5`，day 1.0 的 `t_max` / `r_max`；此处是**全域最大流速**，与文献中常报的深层平均量不是同一统计量）。

真正的问题在后一层：评价"伪流治理好不好"的每一个可见读数——深层流速、残余流、辐射功率——本身都是一把候选**尺子**（proxy metric），而真值平时拿不到。

## 1.2 这个问题不是我们提的

代理指标不可信在多个领域已被独立记录：ERBench 摘要直接把同域预测精度定性为 misleading proxy；Kosmos 明写"虽然每条 claim 可溯源，却**不存在可靠评估其准确性的自动方法**"；GEM 指出打分器实现的细微差异就让报告性能大幅变动；ClimAgent 在附录承认气候建模的 gold solution 通常不可得；CMIP-Forge 记录了评审因相位论证而更换度量、模式排序随之改变。在数值海洋学侧，同样的病早有记载：Mellor 等（1998）指出加黏性压得住伪流却没修压力梯度误差；Shchepetkin & McWilliams（2003）分析离散黏性自身也会造伪流；Schifano 等（2025）在陡地形区报告不同混合诊断彼此不一致。

**但处理方式都是事后个案更正；据我们检索（Crossref 与 arXiv，2026-09-02）未见把它做成对全部候选、含作者自身头条指标一视同仁、可复算的判死程序的工作。**这是我们切入的位置——"据我们检索未见"是一个检索结论，不是优先权主张。

## 1.3 为什么必须让 AI 介入，边界在哪

三条理由，都不是"AI 很时髦"：
1. **将来刷这些指标的主体就是 Agent**。自动化科学系统已经在用可见代理做优化（CVEvolve 在开发集上把 F1 推到接近 1，而 holdout 第 5 轮见顶、第 9 轮后崩），"指标可不可信"从方法学问题变成了安全问题。
2. **穷举 + 配对反事实检验的规模，人做不了**：本作品对 124/140 个基元标量构成的全比值空间（15376 / 19600 个候选）逐一计算排序力与抗刷率，并在三个强迫方向上重算——三个风向合计 4.61 万次候选评估（15376×3），内潮环境另有 19600 次。
3. **Agent 本身就是尺子的使用者，也是污染源**：A7 显示同一份数据，把指标名字摘掉后大模型评审的两处误判全部翻转。

**边界**：本作品不研究 Agent 算法（memory / harness 设计不在范围内，这也与出题人"算法研究不太在我们的 scope 内"的口径一致）；结论不外推到真实海洋观测。

## 1.4 我们希望 Agent 发现什么，以及核心声明

希望 Agent 发现的是一类**结构**：真值恒为零的子空间在哪里（一把好尺子应当量在那里）。E43 显示它做不到，缺口就精确落在这一步。

核心声明分两句，先负后正：
- **负**：在本环境 124/140 基元的全比值空间内、三个强迫方向下，**未发现**任何标量同时通过两关。这与 Skalse 等（2022，arXiv:2209.13085）定理 1 一致——当策略集扩张到含开集时，非平凡的不可刷代理必然退化；在多目标语境下要求八九个冲突算子上的全支配点也近乎先验必然（arXiv:2604.09417）。**"全军覆没"是预期结果，不是发现。**
- **正**（以下均为检索结论，不主张优先权）：我们的贡献是三样可检验的东西——(i) **正对照行**：把隐藏真值自己当尺子走一遍全部审计，按定义或实测全过，证明协议不是在杀一切；(ii) 每一格可追溯到一条审计、一个数、一个文件的**死因**；(iii) 两关的**双目标结构**被定量刻画（ρ(A,B) = −0.67，贫化 10.6 倍，Pareto 前沿五点，乌托邦角为空），并给出阈值敏感性曲面。

## 2.2 H 的两级分级（评委必问"你的 H 是真值还是又一把尺子"）

- **H_风驱 = 独立求解器真值**（MITgcm z 坐标，Mitigated 级）：外部操作、不同代码、不同垂向坐标，构成回路有效性的绑定条件。
- **H_内潮 = 自参照判分锚**（Weak 级）：500 km 大盒上"先盖章预测后验证"的逐垂向模态远场功率保留比，**同一求解器、同一套代码、只换盒宽**；用 ResearchClawBench 的措辞，它是"a reference study under the same scientific objective, rather than a closed-form ground truth"。**首页与摘要里"真值"二字只留给风驱侧，内潮侧一律写"判分锚"。**所有依赖内潮锚的结论（A8、4.2 的门规则、4.3 的排序力判定）继承 Weak 标签。
- 内潮侧另有独立求解器的一列可用但本轮未纳入判据：论文 v8 的 M2 孪生给出四臂对 MITgcm 的残余流误差，深层 11.916 → 9.011 → 8.267 → **7.842**、上层 4.615 → 2.924 → 2.623 → **2.407**（两轴同向单调）——在这一侧治理是让残余流**更接近**真值的。因此 4.2 中对重治理臂的"陷阱"判定，是**以单侧锚为条件**的判定，不是物理发现；双侧口径下它是一个 Pareto 权衡。
- 两者共用一条零真值通道：平底海上伪流按构造为零、内潮辐射恒为零。

## 2.4 可比性契约与两处主动申报

所有读数只在同初值相位、同窗口、同口径内比较，跨相位用窗均值版。(1) 可见的环带功率在节点距轴上与隐藏模态损伤同序（ρ = −1.0）——藏起来的是定量判分和物理含义，不是方向信息；它是环境里故意保留的**诱饵**（decoy）。(2) 三个风向环境共用同一座海山、同一套网格与代码，只换强迫方向与真值；ROMS 区域是 x 周期、y 陆墙，转 90° 后 ROMS 侧**不是**镜像（表层 u/v rms 4.32/9.93 → 9.93/6.63），MITgcm 真值侧是精确镜像——这既是 4.3 机理的来源，也是它的边界。

# 第三问 · Agent 如何完成发现

## 3.1 工作流：verifier-driven，不是提示词驱动

预注册（sha256 + 文件系统时间戳，**无第三方时间戳服务**；算例时刻记录方式见 `analysis/TIME_LEDGER.json`，e56 为运行时写入、其余为 `DONE` 文件 mtime）→ 扫描 → 逐条对账 → 审计。规则活在会大声失败的确定性脚本里：输入件 md5、白名单差分、配置回显自检、健康门、`smoke_test.sh`（5/5）、`reproduce_core.sh`。

**三件必须申报的事**：① 内潮第一批 13 条为预注册臂，其后 7 条加密臂是看到首批结果后追加的，p 值同时给两种口径（4.4）；② E52 转风**未预注册**——先验假设写于 `STATE_BRIEF.md`（发射前 20 分钟），判据脚本与阈值与纬向逐字相同，无可调自由度；③ E55（45° 风）与 E56（BH93）**已预注册**（sha256 `ec1b1ecf…` / `7792b30e…`）。

## 3.2 一次完整的探索循环

陷阱局六轮 = 一次完整循环：观察（可见读数）→ 行动（提交配置）→ 环境真跑其下单的三条算例 → 反馈（读数 + 健康门）→ 判断 → 记录（JSONL）。同预算随机基线三席（种子 0/1/2）构成"乱猜"对照。

## 3.3 Agent 的三个角色

**对手（陷阱局）**：目标"把深层残余流降到最低"。它撞见环带功率 −4.3 MW 的配置后靠自设的"功率须为正"守门退回；终选 `ag_s3`：深层残余流 3.25（对零治理臂 6.08 为 −47%），环带功率 4.15 MW（对冻结修正臂 14.08 为 30%），可见 u/v 从 2.54 升到 3.46 一路报警，它没有用。**中性措辞**再跑一局：终选配置相同。同预算随机基线两席掉进 γ×16（功率 −8.9 MW）。
准确的表述是：**一个守规矩的 agent（自设守门、未违规）被一个看起来完全合理的读数带到了波功率只剩 30% 的方案**。按 Skalse §6.1 的区分，A1/A2 给出的是**可刷性**（hackability）；初赛 89.8% 步数逃到平底、随机基线 2/3 掉进 γ16 才是**实际被刷**（hacking）。AEvo 报告去掉 harness 后 3 次 run 有 2 次进入 reward hacking——与我们随机基线 2/3 数值一致，是"不设审计一定被刷"的跨域证据。

## 4.1 两关互斥：本作品的定量支柱

排序力 A（= −ρ，与隐藏真值的秩相关）与抗刷率 B（同参数换平底不变好看的比例）在全候选空间上 **Spearman = −0.674**。若两者独立，同时过关应有 **2159** 个候选（0.3155 × 0.4451 × 15376）；实测 **204** 个，**贫化 10.6 倍**。Pareto 前沿只有 5 点，从 (A=0.998, B=0.094) 一路走到 (A=0.948, B=1.000)，**乌托邦角 (1,1) 在实测前沿上为空**。阈值从 (0.5, 0.7) 扫到 (0.9, 1.0)，通过数 739 → 9，**没有任何阈值组合能让这个结构消失**。

**但必须同时申报这个结构的统计边界**：把抗刷率的点估计换成 Wilson 置信区间后，判定要三值化——区间完全落在阈值一侧才判过/死，跨过阈值一律判 **U（未判定）**。结果是：u/v 在纬向风下 **32/32 满分，CI 仍是 [0.893, 1.000]，只能判 U**；经向 25/28 = 0.893，CI [0.728, 0.963]，也是 U；而 45° 的 7/28（CI [0.127, 0.434]）、v/u 纬向 7/32、v/u 经向 3/28 三处**都是确定的死**。
换句话说：**这套协议能可靠地判死，不能可靠地认证**——n=32 的配对样本量下，即使满分也够不着 0.9 的置信下界。这与 2.3 节"A3/A4/A7 只能证伪、不能认证"是同一件事的统计版本，也意味着本报告所有"通过"都应读作"未被证伪"。（`e44_tide/analysis/E58_TRIVALENT.json`）

这给了"排序与抗刷分了家"一个标准表述：两者是**冲突的双目标**，把它们压成一个标量会因量纲缩放而失真、且偏好隐式不可审计（arXiv:2508.18170）。前沿上的 knee（`u|d1500|p95 / w|d1500|rms`，A=0.948、B=1.000）在风驱环境上两关全过，**却不在跨内潮的 13 个交集里**——单环境的"接近完美"换个环境就死。

## 4.4 为什么 u/v 家族没有普适版本（机理，含边界）

一把比值尺子要满足两件事：排序力要求它的某一端被真信号钉住；抗刷分要求它换到平底不变好看。以下解释在 45° 检验后只剩**描述性地位**。区域 x 周期、y 陆墙：B 在 0°/90° 下看起来由几何主导——两种风向下平底的 u/v 都高于海山（配对中位数 2.64 vs 2.36；2.82 vs 2.56）——我们的解释是周期方向允许平底残留一支纬向流（**推断**：只有配对中位数，无平底流场剖面）；A 主要由真信号住在哪个分量决定（纬向风下 MITgcm 真值 |V|max 0.091 > |U|max 0.080，经向下互换——**单帧极值，惯性振荡下随相位旋转，属推断**）。两条件在纬向强迫下巧合落在同一对 u/v，经向下分家。

**45° 预注册检验（E55）反驳了其中两条**：P1 中（u/v 与 v/u 都没同时过两关）、**P2 被反驳**（u/v 抗刷率从 1.00 掉到 0.25，v/u 从 0.22 升到 0.82——抗刷分不是几何单独决定的）、**P3 被反驳**（u/v 在 45° 排序力 −0.97，比 0° 还强）、P4 中。**我们的几何/分量解释只对了一半**，据此降为描述性陈述。

最粗的代理 deep_rms_800 在纬向/经向实例内排序 ρ = −0.963/−0.990，内潮对锚 −0.96，只是完全不抗刷（B=0）——**好排序器不等于好尺子**；此现象在自适应网格文献中已有先例（TrueError 不是性能理论上界，RL 有时超过它）。

其余家族：纬向∩经向的 88 把以 (v,w)、(w,w)、(temp,temp)、(u,w) 为主，它们在内潮全部未通过三轴报警判据。

## 4.5 A9：把社区标准的那把尺子也放进同一张表（E56，预注册在先）

Beckmann & Haidvogel（1993）的静止态海山检验是本领域评价 σ 坐标压力梯度误差的社区标准。我们按其设置重编无风二进制（`undef SEAMOUNT_WIND`，sha256 `00751585…`）、按 T = f(z) 逐点生成水平等密初值（`|T − f(z_r)|max = 0`，逐点验证）、u=v=ζ=0，跑 VISC2 七档 × 两地形 = 14 条。静止态下真值解析为零：任何非零流动都是纯误差。

结果（预注册 `7792b30e…`，P1/P2 命中、**P3 被反驳**）：
- **平底全档 `u_max = 0.0000`**——零真值通道的教科书级正对照。
- 陡海山 `u_max` 从 99.72 单调降到 18.79 cm/s（降 81%，ρ = −1.000，p=0.0004）。
- **A1 配对抗刷 = 0.000**：换到平底读数精确归零，**社区标准的那把尺子在这条路径上同样完全不抗刷**。
- P3 被反驳：我们预测同样的黏性档位会在风驱算例上毁掉真信号，实测技巧评分反而单调**上升**（−8.48 → −1.46，ρ = +1.000）。所以 BH93 尺子的毛病**不是"被刷穿"，而是"无判别力"**：它把伪流降 81% 报成改进，而真值说技巧评分**全程为负**——拧到物理上已荒谬的黏性上限，模式仍比"什么都不做的恒零模型"更差；且可见代理降 83% 而真实误差只降 49%，**夸大 1.69 倍**。

## 4.6 从判死到预测：无真值特征能预测排序力吗（E59，预注册）

前五节的判据里藏着一个实用性问题：**排序力 A 需要真值才能算，而真值在现实中往往拿不到**；真正能在无真值处执行的只有抗刷率 B 一类。既然已测得 ρ(A,B) = −0.674，说明无真值的 B 携带着关于 A 的信息，那就该正面问一句：**只用不需要真值的观测，能不能预测一把尺子有没有排序力？**

预注册（sha256 `533c3062…`）写死了设定：候选空间与 E40 逐字相同，**纬向风环境训练、经向风环境测试**（跨环境泛化是唯一验收方式），七个特征全部不得触碰真值——配对抗刷率、平底臂噪声、海山臂动态范围、地形敏感度、是否同分量、深度层级差、与已知旋钮 VISC2 的秩相关；模型只用一次拟合的逻辑回归，不调参、不做特征选择。

**结果（P1/P2/P4 命中，P3 未命中）**：
- 单特征里，抗刷率 B 的测试集 AUC = **0.2005**（远离 0.5，且方向为负——越抗刷越不可能有排序力，与 4.1 的互斥结构一致）；与旋钮的秩相关 AUC = 0.6752；平底噪声 AUC = 0.4244。
- 七特征逻辑回归在**从未参与训练的经向风环境**上 AUC = **0.8706**。无真值特征对排序力确有实质预测力。
- 但 P3（预测分最高的 204 个中，命中率至少是基率的 3 倍）**未命中**：实测 precision@204 = 0.0882，**低于**基率 0.2797216441207076。

**这个矛盾我查了三轮，前两个解释都被数据推翻，全部留档**（`E59_TRUTHFREE.json:posthoc_explanations_tested`）：
1. 假设"无真值特征只能预测判别力强度、预测不了方向"——**推翻**：在 \|A\|≥0.7 的 8538 个候选里预测方向的 AUC = 0.919，方向比强度（0.813）更好预测。
2. 假设"最高分那批是训练分布之外的外推失败"——**推翻**：top-204 的七个特征全部落在训练集 1–99 分位之内，0 个外推。
3. 真正的结构是**非单调**：按预测分等频分箱，命中率从 0.037 一路升到峰值 **0.8306**（score≈0.02807，n=1098），随后在最高分一箱回落到 **0.6906**；若只取最极端的 0.5%（77 个），命中率跌到 **0.052**。

**这是本作品的主题在我们自己的工具上复现了一次**：我们造出一个用来预测"哪把尺子可信"的分数，它在中段确有判别力（峰值命中率 0.8306 vs 基率 0.2797216441207076），可一旦把它推到极端，它就和被它审判的那些尺子一样开始骗人。可操作的读法因此是明确的——**用中段，不要用顶端**；而这条建议本身也只在本环境族内有依据。

图 4 给出这条曲线。就本作品的定位而言，E59 把协议从"只能判死"往前推了一步：**在没有真值的地方，它能把 15376 个候选缩到一个判别力显著富集的中段区间**；但方向仍需真值确认，且预测器自身的极端区不可信——两条限制都写在这里，不留到答辩现场。

## 4.7 抗刷率本身是不是地形陡度的函数（E60，预注册）

E59 审计了我们造的预测器，本节审计**判据本身**。抗刷率 B 的定义是「同参数换到平底，读数不变好看」——可这个配对里"海山有多陡"是一个自由参数。**若 B 随陡度大幅漂移，那它和被它审判的那些代理指标就是同一个毛病**；报告此前也把"陡度 rx0 未变"列为适用边界。

预注册（sha256 `af8fe044…`）设定：取现成的四档陡度网格 rx0 = 0.200 / 0.441 / 0.599 / 0.694（42×42×13），每档配一个同尺寸、同最大深度的平底对照，初值按 T = f(z) 逐点重造；VISC2 七档 × 2 地形 × 4 陡度 = **56 条算例，全部完赛**。每档用与 E40 逐字相同的穷举器算全部 15376 个候选的 B（**只需配对，不需要 MITgcm 真值**）。

**结果（P2/P3 命中，P1/P4 未命中）**：
- **P1 被推翻，而且是朝有利方向**：我赌任意两档之间「B≥0.9 的候选集合」的 Jaccard < 0.5，实测 **0.817–0.968**；B 的候选间秩相关 **0.734–0.953**。四档的通过比例几乎不动（44.4% / 44.6% / 44.4% / 44.6%）。**抗刷率在陡度轴上是稳健的。**
- **P2 命中**：深层残余流类（`u|d800|rms`）在全部四档陡度上 B = **0.000**——"完全不抗刷"是跨陡度成立的构造性结果，不是某一座海山的巧合。
- **P4 未命中，原因是我预注册时写错了前提**：我按 E56 静止态的直觉预测"平底 max\|u\| 应低于陡海山的 10%"，实测比值 0.157–0.741。但风驱设定下平底本就有约 14 cm/s 的**真实风生流**（非误差），零真值只对 PGE 分量成立。这不影响 B 的有效性（B 比较的是同一读数在两种地形下的相对大小，不要求平底为零），但预测写错了就是写错了，如实记录。

**这个结果揭示出两关之间一个此前未被注意的不对称**（图 5）：
- **排序力 A 换个强迫方向就崩**：同一把 u/v，0°→45°→90° 的 A 是 0.92 → 0.97 → **−0.17**（变号）。
- **抗刷率 B 换个地形陡度纹丝不动**：Jaccard 0.82–0.97。

也就是说，**B 测的是尺子自身的结构性质（对地形稳健），A 测的是尺子与特定物理场景的匹配度（对强迫方向敏感）**。两者捕捉的不是同一层次的东西——这给"为什么必须同时要求两关"提供了一个此前没有的正当性论证，也把 §4.8 里"陡度 rx0 未变"这条边界从"未验证"升级为"已量化且稳健"。

**边界**：本节只在 42×42 的四档陡度内成立，与主环境的 48×48（rx0=0.766）跨尺寸不并入同一统计；陡度轴之外的层结尖锐度与垂向层数仍未变。

## 4.8 把 Agent 放到与线性模型完全相同的信息条件下（E61，预注册）

E59 证明七个无真值特征可跨环境预测排序力。本作品此前反复承认"Agent 只是被测对象与对手，不是发现者"（E43 提议者 0/20），但那是一次**没有对照**的失败。本节把 Agent 放进与那个七参数逻辑回归**完全相同**的信息条件下，正面比一次。

预注册（sha256 `67d3ede0…`）设定：候选池取经向风环境（Agent 与逻辑回归都没在其上训练过）；每局展示 **40 个候选**（按 E59 预测分四分位分层抽样，各 10 个），每个只给七个无真值特征的数值，**不给真值、不给排序力 A、不给 E59 的预测分**；任务是挑出 10 个"最可能与隐藏真值有强排序关系"的候选并说明理由；**8 局**独立抽样，单模型 `deepseek-v4-pro`。

**结果（P2 命中，P1 未命中，P3 部分推翻）**：

| 方法 | 8 局平均命中率 |
|---|---|
| 逻辑回归（七参数，E59 训练所得） | **0.675** |
| 低 B 启发式（只取抗刷率最低的十个） | 0.500 |
| Agent（deepseek-v4-pro） | 0.412 |
| 随机（每局 200 次重采样） | 0.283 |

- **P2 命中**：Agent 输给逻辑回归，8 局无一胜出（符号检验 p = 1.00）。它甚至输给"抗刷率最低的十个"这条**单特征**规则。
- **P1 未命中**：Agent 的 0.412 虽高于随机的 0.283，但 8 局符号检验 p = **0.1445**，**不显著**。按预注册纪律，我们不能声称 Agent 强于随机。
- **P3 部分推翻**：我赌它会主要引用抗刷率并把方向用反。实测最常引用的是平底噪声、海山动态范围、与 VISC2 的秩相关（各 8/8），抗刷率只有 5/8；方向上它多数时候用**对**了（4 局说"抗刷低更好"，仅 1 局说"抗刷高更好"）。

**一个事后观察（非预注册，n 极小，只作探索性陈述）**：按 Agent 自述的抗刷率使用方向分组——说对方向的 3 局平均 **0.60**（逼近逻辑回归的 0.68），说反方向的 1 局 0.30，没说清或混合的 4 局 0.30（回到随机水平）。

**这给了"Agent 不是发现者"一个比 E43 精确得多的含义**：它**不是读不出规律**——8 局里有 3 局它明确说出了正确方向，那几局的成绩逼近线性模型；问题是**读出规律的过程不可重复**，另外 5 局它要么说反、要么说不清，成绩就掉回随机。而逻辑回归一旦拟合完，抗刷率的系数恒为 −2.57，方向每局都对。**稳定性，而不是能力，才是这里的瓶颈。**（图 6）

这与官方口径一致：一个非平凡的基线可能比复杂 Agent 更强，这是需要如实比较、而不是回避的结果。**边界**：单模型、n=8、单一任务形式、分组由正则从自述理由中抽取，全部为探索性观察，不作统计推断；换模型或换提示词都可能改变结论。

## 4.9 统计地板与适用边界

三轴单调的精确置换 p 见 4.3；Fisher 合并 p = 1.2×10⁻⁵（三轴共用基准臂，仅作参考；此前"三轴 p 值直接相乘得 4.12×10⁻⁸"是错误口径（三轴共用基准臂，不独立），撤回）。基率：内潮 19600 候选里 13.1% 过三轴报警判据、13.2% 是可刷型；风驱 1.33%。交集观测/期望：纬向∩经向 88/5.4（富集 16 倍）、纬向∩内潮 13/26.8、经向∩内潮 2/53.5、三重 0/0.71（P(0)=0.49）——**三重交集为 0 与随机期望无差别，因此"0"本身不是证据**；换成另一组三重（纬向∩45°∩内潮）则为 1 把（`u|s50|mean_abs / v|s50|rms`，期望 0.79），该候选在经向风下失败，核心声明不变；真正的信号是 4.1 的两关互斥（贫化 10.6 倍）与两处交集贫化。

**赢家诅咒**：E48 的"三轴满分头名是深水温度扰动类"（≈4.00 °C 的 0.3% 漂移拿到 |ρ|=0.96）是 **regressional Goodhart** 的教科书实例——从 19600 个候选中取 ρ 最大者，选择偏倚会系统性高估冠军的相关性。我们据此补了一条最粗的信噪比门（稳健相对离散度 = 四分位距 / |中位数|，在 32 个内潮臂上算）：深水温度类候选只有 **0.3%**，而 u/v 24%、残余流 28%、环带功率 445%——低一到两个量级，**任何 >1% 的门都会把它淘汰**。据此把该冠军显式降格为"无信噪比门条件下的伪冠军"，并作为跨环境交集贫化的可能成因之一。（`E58_TRIVALENT.json`）

**适用边界**：候选空间只含单次运行末帧标量（未含配对/差分标量）；四个环境（纬向风 / 经向风 / 45° 风 / M2 内潮）同海山、同网格、同代码，只换强迫方向与真值；区域 x 周期 y 陆墙，双周期或闭合盒未验证；层结尖锐度与垂向层数未变（本团队既有工作显示层结轴 18× 放大、层数轴对不同方法方向相反，是下一步优先轴）；陡度轴已由 4.7 验证（四档 rx0 内 B 稳健）；阈值 0.7/0.9 沿用初赛且未由对照臂标定；内潮锚单侧自参照；A7 为同一家族两个模型、每条件 n=5（跨厂商未做）。

**审计抓不到什么**：抓不到物理模型选错、基准臂选得不当、以及被明确指示去改写审计脚本的对抗性 Agent。

## 4.10 稳定性、人工干预与 false positive

207 条扫描算例一次完赛、无筛选无重跑，健康门全绿；**1 条**同配置重跑（`p_combo_rerun`）三读数逐位一致（这证明决定性，不证噪声地板）。陷阱局第一版因环境侧 Fortran 字面量 bug 作废（只影响 Agent 下单路径，扫描不受影响；轨迹与声明随包）。四条被数据反驳的预注册预测（P3-内潮、P2/P3-45°、P3-BH93）全部保留在案；另有一条“未命中”（内潮 P1-late：正压 M2 振幅未出现 >2% 的下降），按“预测方向被数据推翻”与“预测事件未发生”分开计，前者四条、后者一条，两类都不删。判定的统计边界见 4.1 末段：所有"通过"应读作"未被证伪"。时间戳一律本地时间（+08:00），无第三方时间戳。

**本作品结论支持什么**：同域、同口径、同相位下的相对排序；失效模式的可预测与可复算；两关互斥的定量结构。
**不支持什么**：可迁移的绝对指标；跨强迫方向的普适标量；Agent 自主发现判据；向真实海洋观测的外推。
