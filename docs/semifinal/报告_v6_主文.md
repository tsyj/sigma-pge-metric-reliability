# 谁来给尺子打分：σ 坐标伪流环境中的代理指标可靠性探索
## 复赛《科学发现与环境定义报告》

> **古德哈特定律（Strathern 1997）说：当一个指标成为目标，它就不再是一个好指标。** 我们这项工作把这句话做成一个可运行的实例：在 σ 坐标海洋模式的伪流治理上，把真值藏起来，问一句"这些读数配不配当判据"。
> 一句话结论：**任何单个强迫下都能找到同时通过两关的候选（纬向风 204 个、经向风 407 个、内潮 2574 个），但没有一个候选能在换了强迫方向之后仍然通过**——而这两关在全部 15376 个候选上呈显著负相关（ρ = −0.67，两关同过 204 个 vs 独立期望 2159 个，贫化 10.6 倍），乌托邦角在实测 Pareto 前沿上为空。所以我们交的不是一把尺子，是一套给尺子打分的**审计协议**，并用它审了我们自己的隐藏判分，也审了我们自己论文的头条指标。
> 我们这项工作按官方说法属「**元环境 / 评测范式**」类（手册 05 节），并已按其门槛「以具体领域实例跑通」：σ 坐标伪流治理这一具体领域问题、207 条真跑算例、九项审计算子。
> 附录 A 为初赛定稿正文；附录 B 为实验编号 E40–E62 全表与数字出处；附录 C 为下一步的对抗式双 Agent 环境规格；附录 D 为正文移出的实验细节、预注册逐条核对与官方自检自答。全部数字的单一真源是仓库 `e44_tide/analysis/`、`e52/`、`e55/`、`e56/` 下的 JSON，`bash scripts/reproduce_core.sh` 一键重算。

# 第一问 · 科学问题与发现目标

## 1.1 问题（初赛定稿，原文见附录 A）

σ（地形跟随）坐标海洋模式在陡地形上会凭空长出伪流。初赛用独立求解器量化过：同一座海山、同样的风，第 1 天结束时全域最大流速，MITgcm z 坐标真值 **9.24 cm/s**，ROMS σ 坐标 **99.53 cm/s**（`ledger/headline_table.json`，run `e2_7fc7950d63bc`，真值目录 `truth/sw_viscAz_1pEm5`，day 1.0 的 `t_max` / `r_max`；此处是**全域最大流速**，与文献中常报的深层平均量不是同一统计量）。

真正的问题在后一层：评价"伪流治理好不好"的每一个可见读数——深层流速、残余流、辐射功率——本身都是一把候选**尺子**（proxy metric），而真值平时拿不到。

## 1.2 这个问题不是我们提的

代理指标不可信在多个领域已被独立记录（ERBench、Kosmos、GEM、ClimAgent、CMIP-Forge；数值海洋学侧 Mellor 等 1998、Shchepetkin & McWilliams 2003、Schifano 等 2025；逐条对照见附录 D-1.2，文献编号见附录 B）。**但处理方式都是事后个案更正；据我们检索（Crossref 与 arXiv，2026-09-02）未见有工作把它做成一套可复算的失效判定程序：对全部候选一视同仁，且把作者自己的头条指标也放进去。**这是我们切入的位置——"据我们检索未见"是一个检索结论，不是优先权主张。

## 1.3 为什么必须让 AI 介入，边界在哪

1. **将来刷这些指标的主体就是 Agent**（CVEvolve 在开发集上把 F1 推到接近 1，而 holdout 第 5 轮见顶、第 9 轮后崩），"指标可不可信"从方法学问题变成了安全问题。
2. **穷举 + 配对反事实检验的规模，人做不了**：我们这项工作对 124/140 个基元标量构成的全比值空间（15376 / 19600 个候选）逐一计算排得准的程度与抗糊弄的程度，并在三个强迫方向上重算——三个风向合计 4.61 万次候选评估（15376×3），内潮环境另有 19600 次。
3. **Agent 本身就是尺子的使用者，也是污染源**：A7 显示同一份数据，把指标名字摘掉后大模型评审的两处误判全部翻转。

**边界**：我们这项工作不研究 Agent 算法（memory / harness 设计不在范围内，这也与出题人"算法研究不太在我们的 scope 内"的计算方式一致）；结论不外推到真实海洋观测。

## 1.4 我们希望 Agent 发现什么，以及核心声明

希望 Agent 发现的是一类**结构**：真值恒为零的子空间在哪里（一把好尺子应当量在那里）。E43 显示它做不到，缺口就精确落在这一步。核心声明分两句，先负后正：
- **负**：在本环境 124/140 基元的全比值空间内，任何单个强迫下都存在同时通过两关的候选，但**未发现**任何候选能在三个强迫方向下都通过。并且，即便只看单个强迫，两关也是互斥的：同时通过的数量比两关独立时该有的少 10.6 倍（4.1）。这与 Skalse 等（2022，arXiv:2209.13085）定理 1 一致——当策略集扩张到含开集时，非平凡的不可刷代理必然退化；在多目标语境下要求九个冲突算子上的全支配点也近乎先验必然（arXiv:2604.09417）。**"全军覆没"是预期结果，不是发现。**
- **正**（以下均为检索结论，不主张优先权）：我们的贡献是三样可检验的东西——(i) **正对照行**：把隐藏真值自己当尺子走一遍全部审计，按定义或实测全过，证明协议不是在杀一切；(ii) 每一格可追溯到一条审计、一个数、一个文件的**死因**；(iii) 两关的**双目标结构**被定量刻画（ρ(A,B) = −0.67，贫化 10.6 倍，Pareto 前沿五点，乌托邦角为空），并给出阈值敏感性曲面。

# 第二问 · Environment / Benchmark 定义

环境写成四元组 **(K, V, H, A)**（图 1）。前三项初赛已有；复赛把 **A（审计算子集）列为环境定义的第四个正式组成部分**——这正是文献里空着的一格：EurekAgent 把环境工程正式命名并给出四维（权限/产物/预算/人在环），**没有审计维**。隔离与隐藏评测器本身是本领域现行做法（AEvo 明写 agents cannot inspect evaluator internals；CVEvolve 的 holdout；ERBench 的保密评测集）——我们的 H 设计只能算**沿用**，不是新意。新意在 A，以及我们用 A 审了 H 自身。

## 2.2 H 的两级分级：哪一侧算真值，哪一侧只是判分锚

- **H_风驱 = 独立求解器真值**（MITgcm z 坐标，Mitigated 级）：外部操作、不同代码、不同垂向坐标，构成回路有效性的绑定条件。
- **H_内潮 = 自参照判分锚**（Weak 级）：500 km 大盒上"先提前登记的预测后验证"的逐垂向模态远场功率保留比，**同一求解器、同一套代码、只换盒宽**；用 ResearchClawBench 的措辞，它是"a reference study under the same scientific objective, rather than a closed-form ground truth"。**首页与摘要里"真值"二字只留给风驱侧，内潮侧一律写"判分锚"。**所有依赖内潮锚的结论（A8、4.2 的门规则、4.3 的排得准的程度判定）继承 Weak 标签。
- 内潮侧另有独立求解器的一列可用但本轮未纳入判据：论文 v8 的 M2 孪生给出四组对 MITgcm 的残余流误差，深层 11.916 → 9.011 → 8.267 → **7.842**、上层 4.615 → 2.924 → 2.623 → **2.407**（两轴同向单调）——在这一侧治理是让残余流**更接近**真值的。因此 4.2 中对重治理组的"陷阱"判定，是**以单侧锚为条件**的判定，不是物理发现；双侧计算方式下它是一个 Pareto 权衡。
- 两者共用一条零真值通道：平底海上伪流按构造为零、内潮辐射恒为零。

## 2.4 可比性契约与两处主动申报

所有读数只在同初值相位、同窗口、同一种计算方式内比较，跨相位用窗均值版。(1) 可见的环带功率在节点距轴上与隐藏模态损伤同序（ρ = −1.0）——藏起来的是定量判分和物理含义，不是方向信息；它是环境里故意保留的一个**陷阱配置**：可见读数会变好看，隐藏判分却在恶化。(2) 三个风向环境共用同一座海山、同一套网格与代码，只换强迫方向与真值；ROMS 区域是 x 周期、y 陆墙，转 90° 后 ROMS 侧**不是**镜像（表层 u/v rms 4.32/9.93 → 9.93/6.63），MITgcm 真值侧是精确镜像——这既是 4.3 机理的来源，也是它的边界。

# 第三问 · Agent 如何完成发现

## 3.1 工作流：verifier-driven，不是提示词驱动

预注册（sha256 + 文件系统时间戳，**无第三方时间戳服务**；算例时刻记录方式见附录 D-2.1）→ 扫描 → 逐条对账 → 审计。规则活在会大声失败的确定性脚本里：输入件 md5、白名单差分、配置回显自检、健康门、`smoke_test.sh`（5/5）、`reproduce_core.sh`。**三件必须申报的事**：① 内潮第一批 13 条为事先登记的实验组，其后 7 条后加的采样组是看到首批结果后追加的，p 值同时给两种计算方式（4.4）；② E52 转风**未预注册**——先验假设写于 `STATE_BRIEF.md`（发射前 20 分钟），判据脚本与阈值与纬向逐字相同，无可调自由度；③ E55（45° 风）与 E56（BH93）**已预注册**（sha256 `ec1b1ecf…` / `7792b30e…`）。

## 3.2 一次完整的探索循环

陷阱局六轮 = 一次完整循环：观察（可见读数）→ 行动（提交配置）→ 环境真跑其下单的三条算例 → 反馈（读数 + 健康门）→ 判断 → 记录（JSONL）。同预算随机基线三席（种子 0/1/2）构成"乱猜"对照。

## 3.3 Agent 的三个角色（详细叙述与先行工作对照见附录 D-3.3）

**对手（陷阱局）**：目标"把深层残余流降到最低"。终选 `ag_s3`：深层残余流 3.25（对未做任何治理的那组 6.08 为 −47%），环带功率 4.15 MW（对固定参考态修正的那组 14.08 为 30%），可见 u/v 从 2.54 升到 3.46 一路报警，它没有用；**中性措辞**再跑一局终选配置相同；同预算随机基线两席掉进 γ×16（功率 −8.9 MW）。准确的表述是：**一个守规矩的 agent（自设守门、未违规）被一个看起来完全合理的读数带到了波功率只剩 30% 的方案**。按 Skalse §6.1 的区分，A1/A2 给出的是**可刷性**；初赛 89.8% 步数逃到平底、随机基线 2/3 掉进 γ16 才是**实际被糊弄**。

**评审（判据局 / 换名局）**：真名 / 匿名（M1–M7）/ 互换名三组配对，把"名字"隔离为因果通道。真名版把环带功率标可信 3/5、把 u/v 标可刷 4/5；匿名版降到 1/5 与 1/5；互换名后，穿着"环带功率"外衣的 u/v 数据仍被疑 4/5；阴性对照：残余流两版都被标可刷 5/5。病症的学名是 **authority borrowing**。**跨模型复核（E62）**换到 `deepseek-v4-flash`（每条件 n=5）：真名下环带功率被判可信 **3/5**、匿名后 **1/5**，两个模型完全一致；换名局 4/5（pro）与 5/5（flash）方向一致；**但真名下 u/v 被判可刷在 pro 上是 4/5、在 flash 上只有 2/5**。因此可主张的只有**"有名字的头条指标更容易被信任"在两个模型上都成立**；"有名字的候选指标更容易被怀疑"只在 pro 上明显。结论限定在同一家族的两个模型、每条件 n=5 之内，跨厂商复核仍未做。

**提议者（E43，初赛）**：30 轮（20 轮格式有效）0 通过；按穷举基率 1.33%，20 抽 0 中的概率 0.77——与随机无差别。**我们独有的是缺口的粒度**：缺口具体到"构造零真值子空间"这一步；4.8 进一步把它定位到"稳定性而非能力"；且我们坚持**可读的符号积木**形式，因为不可读的策略无法被 A1–A9 逐格审计。

## 4.1 两关互斥：我们这项工作的定量支柱

排得准的程度 A（= −ρ，与隐藏真值的秩相关取反）与抗糊弄的程度 B（同参数换平底不变好看的比例）在全候选空间上 **Spearman = −0.674**。**全文凡写"排得准的程度 A"一律取 A = −ρ，正值为好；括号里另给的 ρ 才是原始秩相关。**（注意：这个 A 与环境四元组 (K, V, H, A) 里的审计算子集 A、以及附录 A 无关；抗糊弄的程度 B 也与 B 样条无关。）若两者独立，同时过关应有 **2159** 个候选（0.3155 × 0.4451 × 15376）；实测 **204** 个，**贫化 10.6 倍**。Pareto 前沿只有 5 点，从 (A=0.998, B=0.094) 一路走到 (A=0.948, B=1.000)，**乌托邦角 (1,1) 在实测前沿上为空**。阈值从 (0.5, 0.7) 扫到 (0.9, 1.0)，通过数 739 → 9，**没有任何阈值组合能让这个结构消失**。

**但必须同时申报这个结构的统计边界**：把抗糊弄的程度的点估计换成 Wilson 置信区间后，判定要三值化——区间完全落在阈值一侧才判过/死，跨过阈值一律判 **U（未判定）**。结果是：u/v 在纬向风下 **32/32 满分，CI 仍是 [0.893, 1.000]，只能判 U**；经向 25/28 = 0.893，CI [0.728, 0.963]，也是 U；而 45° 的 7/28（CI [0.127, 0.434]）、v/u 纬向 7/32、v/u 经向 3/28 三处**都是确定的死**。换句话说：**这套协议能可靠地判定一把尺子失效，却不能可靠地确认它有效**——n=32 的配对样本量下，即使满分也够不着 0.9 的置信下界。这与 2.3 节"A3/A4/A7 只能证伪、不能认证"是同一件事的统计版本，也意味着本报告所有"通过"都应读作"未被证伪"。（`e44_tide/analysis/E58_TRIVALENT.json`）

这给了"排序与抗糊弄的程度了家"一个标准表述：两者是**冲突的双目标**，把它们压成一个标量会因量纲缩放而失真、且偏好隐式不可审计（arXiv:2508.18170）。前沿上的 knee（`u|d1500|p95 / w|d1500|rms`，A=0.948、B=1.000）在风驱环境上两关全过，**却不在跨内潮的 13 个交集里**——单环境的"接近完美"换个环境就死。

## 4.4 为什么 u/v 家族没有普适版本（机理，含边界；全文见附录 D-4.4）

一把比值尺子要满足两件事：排得准的程度要求它的某一端被真信号钉住；抗糊弄的程度要求它换到平底不变好看。我们最初的几何/分量解释（B 由 x 周期、y 陆墙的几何主导，A 由真信号住在哪个分量决定）在 **45° 预注册检验（E55）中被反驳了两条**：P1 中（u/v 与 v/u 都没同时过两关）、**P2 被反驳**（u/v 抗糊弄的程度从 1.00 掉到 0.25，v/u 从 0.22 升到 0.82——抗糊弄的程度不是几何单独决定的）、**P3 被反驳**（u/v 在 45° 排得准的程度 −0.97，比 0° 还强）、P4 中。**我们的几何/分量解释只对了一半**，据此降为描述性陈述。最粗的代理 deep_rms_800 在纬向/经向实例内排序 ρ = −0.963/−0.990，内潮对锚 −0.96，只是完全不抗糊弄（B=0）——**好排序器不等于好尺子**。其余家族：纬向∩经向的 88 把以 (v,w)、(w,w)、(temp,temp)、(u,w) 为主，它们在内潮全部未通过三轴报警判据。

## 4.5 A9：把社区标准的那把尺子也放进同一张表（E56，预注册在先）

Beckmann & Haidvogel（1993）的静止态海山检验是本领域评价 σ 坐标压力梯度误差的社区标准。我们按其设置重编无风二进制、按 T = f(z) 逐点生成水平等密初值、u=v=ζ=0，跑 VISC2 七档 × 两地形 = 14 条；静止态下真值解析为零，任何非零流动都是纯误差。结果（预注册 `7792b30e…`，P1/P2 命中、**P3 被反驳**）：**平底全档 `u_max = 0.0000`**——零真值通道的教科书级正对照；陡海山 `u_max` 从 99.72 单调降到 18.79 cm/s（降 81%，ρ = −1.000，p=0.0004）；**A1 配对抗糊弄 = 0.000**——社区标准的那把尺子在这条路径上同样完全不抗糊弄。P3 被反驳：我们预测同样的黏性档位会在风驱算例上毁掉真信号，实测技巧评分反而单调**上升**（−8.48 → −1.46，ρ = +1.000）。所以 BH93 尺子的毛病**不是"被糊弄过去"，而是"无判别力"**：它把伪流降 81% 报成改进，而真值说技巧评分**全程为负**；且可见代理降 83% 而真实误差只降 49%，**夸大 1.69 倍**。详细设计、预注册原文与逐条核对见附录 D-4.5。

## 4.6 从判定失效到事先预测：不用真值能不能预测排得准的程度（E59，预注册）

**排得准的程度 A 需要真值才能算，而真值在现实中往往拿不到**；既然已测得 ρ(A,B) = −0.674，无真值的 B 就携带着关于 A 的信息。预注册（sha256 `533c3062…`）写死了设定：候选空间与 E40 逐字相同，**纬向风环境训练、经向风环境测试**，七个特征全部不得触碰真值，模型只用一次拟合的逻辑回归，不调参、不做特征选择。**结果（P1/P2/P4 命中，P3 未命中）**：单特征里抗糊弄的程度 B 的测试集 AUC = **0.2005**（方向为负——越抗糊弄越不可能有排得准的程度，与 4.1 的互斥结构一致）；七特征逻辑回归在**从未参与训练的经向风环境**上 AUC = **0.8706**；但 P3 未命中——实测 precision@204 = 0.0882，**低于**基率 0.280。这个矛盾我们查了三轮，前两个解释（只能预测强度不能预测方向；最高分那批是外推失败）都被数据推翻并全部留档，真正的结构是**非单调**：按预测分等频分箱，命中率从 0.037 一路升到峰值 **0.8306**，随后在最高分一箱回落到 **0.6906**；只取最极端的 0.5%（77 个）时跌到 **0.052**（图 4）。**这是我们这项工作的主题在我们自己的工具上复现了一次**：预测分在中段确有判别力，推到极端就和被它审判的那些尺子一样开始骗人——可操作的读法是**用中段，不要用顶端**。E59 把协议从"只能事后判定失效"往前推了一步：在没有真值的地方，它能把 15376 个候选缩到一个判别力显著富集的中段区间；但方向仍需真值确认，且预测器自身的极端区不可信。详细设计、预注册原文与逐条核对见附录 D-4.6。

## 4.7 抗糊弄的程度本身是不是地形陡度的函数（E60，预注册）

抗糊弄的程度 B 的配对里"海山有多陡"是一个自由参数；若 B 随陡度大幅漂移，它和被它审判的那些代理指标就是同一个毛病。预注册（sha256 `af8fe044…`）：四档陡度 rx0 = 0.200 / 0.441 / 0.599 / 0.694（42×42×13），每档配同尺寸平底对照，VISC2 七档 × 2 地形 × 4 陡度 = **56 条算例，全部完赛**；每档用与 E40 逐字相同的穷举器算全部 15376 个候选的 B（只需配对，不需要真值）。**结果（P2/P3 命中，P1/P4 未命中）**：**P1 被推翻，而且是朝有利方向**——我们赌任意两档之间「B≥0.9 的候选集合」的 Jaccard < 0.5，实测 **0.817–0.968**，B 的候选间秩相关 **0.734–0.953**，四档通过比例几乎不动（44.4% / 44.6% / 44.4% / 44.6%），**抗糊弄的程度在陡度轴上是稳健的**；**P2 命中**：深层残余流类（`u|d800|rms`）在全部四档陡度上 B = **0.000**；P4 未命中是我们预注册时写错了前提（风驱设定下平底本就有约 14 cm/s 的真实风生流，实测比值 0.157–0.741），不影响 B 的有效性，照实记下来。由此揭示两关之间一个此前未被注意的**不对称**（图 5）：同一把 u/v，0°→45°→90° 的排得准的程度 A 是 0.92 → 0.97 → **−0.17**（变号），而抗糊弄的程度 B 换地形陡度纹丝不动（Jaccard 0.82–0.97）。**B 测的是尺子自身的结构性质（对地形稳健），A 测的是尺子与特定物理场景的匹配度（对强迫方向敏感）**——这给"为什么必须同时要求两关"提供了此前没有的正当性论证，也把 4.9 里"陡度 rx0 未变"这条边界升级为"已量化且稳健"。**边界**：只在 42×42 的四档陡度内成立，与主环境的 48×48（rx0=0.766）不并入同一统计。详细设计、预注册原文与逐条核对见附录 D-4.7。

## 4.8 把 Agent 放到与线性模型完全相同的信息条件下（E61，预注册）

E43 的"提议者 0/20"是一次**没有对照**的失败；本节把 Agent 放进与 E59 七参数逻辑回归**完全相同**的信息条件下正面比一次。预注册（sha256 `67d3ede0…`）：候选池取经向风环境（两者都没在其上训练过），每局展示 **40 个候选**、只给七个无真值特征、**不给真值、不给排得准的程度 A、不给 E59 的预测分**，挑出 10 个并说明理由，**8 局**独立抽样，单模型 `deepseek-v4-pro`。**结果（P2 命中，P1 未命中，P3 部分推翻）**：8 局平均命中率——逻辑回归 **0.675**、低 B 单特征启发式 0.500、Agent 0.412、随机 0.283（图 6）。**P2 命中**：Agent 输给逻辑回归，8 局无一胜出（符号检验 p = 1.00），甚至输给"抗糊弄的程度最低的十个"这条单特征规则；**P1 未命中**：Agent 高于随机但 8 局符号检验 p = **0.1445**，不显著，按预注册纪律不能声称强于随机；P3 部分推翻：它最常引用的是平底噪声、海山动态范围、与 VISC2 的秩相关（各 8/8），抗糊弄的程度只有 5/8，方向上多数时候用对了。事后观察（非预注册，n 极小）：说对抗糊弄的程度方向的 3 局平均 **0.60**（逼近逻辑回归的 0.68），说反或没说清的 5 局回到 0.30。**这给"Agent 不是发现者"一个比 E43 精确得多的含义：它不是读不出规律，而是读出规律的过程不可重复**——逻辑回归的抗糊弄的程度系数恒为 −2.57，方向每局都对。**稳定性，而不是能力，才是这里的瓶颈。**这与官方说法一致：一个非平凡的基线可能比复杂 Agent 更强。**边界**：单模型、n=8、单一任务形式，全部为探索性观察，不作统计推断。详细设计、预注册原文与逐条核对见附录 D-4.8。

## 4.9 统计显著性、基率与适用边界

三轴单调的精确置换 p 见 4.3；Fisher 合并 p = 1.2×10⁻⁵（三轴共用基准组，仅作参考；此前"三轴 p 值直接相乘得 4.12×10⁻⁸"是算错了（三轴共用基准组，不独立），撤回）。基率：内潮 19600 候选里 13.1% 过三轴报警判据、13.2% 是可刷型；风驱 1.33%。交集观测/期望：纬向∩经向 88/5.4（富集 16 倍）、纬向∩内潮 13/26.8、经向∩内潮 2/53.5、三重 0/0.71（P(0)=0.49）——**三重交集为 0 与随机期望无差别，因此"0"本身不是证据**；换成另一组三重（纬向∩45°∩内潮）则为 1 把（`u|s50|mean_abs / v|s50|rms`，期望 0.79），该候选在经向风下失败，核心声明不变；真正的信号是 4.1 的两关互斥（贫化 10.6 倍）与两处交集贫化。

**赢家诅咒**：E48 的"三轴满分头名是深水温度扰动类"（≈4.00 °C 的 0.3% 漂移拿到 |ρ|=0.96）是 **regressional Goodhart** 的教科书实例——从 19600 个候选中取 ρ 最大者，选择偏倚会系统性高估冠军的相关性。我们据此补了一条最粗的信噪比门（稳健相对离散度 = 四分位距 / |中位数|，在 32 个内潮组上算）：深水温度类候选只有 **0.3%**，而 u/v 24%、残余流 28%、环带功率 445%——低一到两个量级，**任何 >1% 的门都会把它淘汰**。据此把该冠军显式降格为"无信噪比门条件下的伪冠军"，并作为跨环境交集贫化的可能成因之一。（`E58_TRIVALENT.json`）

**适用边界**：候选空间只含单次运行末帧标量（未含配对/差分标量）；四个环境（纬向风 / 经向风 / 45° 风 / M2 内潮）同海山、同网格、同代码，只换强迫方向与真值；区域 x 周期 y 陆墙，双周期或闭合盒未验证；层结尖锐度与垂向层数未变（本团队既有工作显示层结轴 18× 放大、层数轴对不同方法方向相反，是下一步优先轴）；陡度轴已由 4.7 验证（四档 rx0 内 B 稳健）；阈值 0.7/0.9 沿用初赛且未由对照组标定；内潮锚单侧自参照；A7 为同一家族两个模型、每条件 n=5（跨厂商未做）。

**审计抓不到什么**：抓不到物理模型选错、基准组选得不当、以及被明确指示去改写审计脚本的对抗性 Agent。

## 4.10 稳定性、人工干预与 false positive

207 条扫描算例一次完赛、无筛选无重跑，健康门全部通过；**1 条**同配置重跑（`p_combo_rerun`）三读数逐位一致（这证明计算是确定性的，但不能用来估计读数本身的随机起伏有多大）。陷阱局第一版因环境侧 Fortran 字面量 bug 作废（只影响 Agent 下单路径，扫描不受影响；轨迹与声明随包）。四条被数据反驳的预注册预测（P3-内潮、P2/P3-45°、P3-BH93）全部保留下来，一条没删；另有一条“未命中”（内潮 P1-late：正压 M2 振幅未出现 >2% 的下降），按“预测方向被数据推翻”与“预测事件未发生”分开计，前者四条、后者一条，两类都不删。判定的统计边界见 4.1 末段：所有"通过"应读作"未被证伪"。时间戳一律本地时间（+08:00），无第三方时间戳。

**我们这项工作结论支持什么**：同域、同一种计算方式、同相位下的相对排序；失效模式的可预测与可复算；两关互斥的定量结构。
**不支持什么**：可迁移的绝对指标；跨强迫方向的普适标量；Agent 自主发现判据；向真实海洋观测的外推。
