## D-3.3 Agent 的三个角色：详细叙述与先行工作对照（对应正文 3.3）

**对手（陷阱局）**：目标"把深层残余流降到最低"。它撞见环带功率 −4.3 MW 的配置后靠自设的"功率须为正"守门退回；终选 `ag_s3`：深层残余流 3.25（对未做任何治理的那组 6.08 为 −47%），环带功率 4.15 MW（对固定参考态修正的那组 14.08 为 30%），可见 u/v 从 2.54 升到 3.46 一路报警，它没有用。**中性措辞**再跑一局：终选配置相同。同预算随机基线两席掉进 γ×16（功率 −8.9 MW）。
准确的表述是：**一个守规矩的 agent（自设守门、未违规）被一个看起来完全合理的读数带到了波功率只剩 30% 的方案**。按 Skalse §6.1 的区分，A1/A2 给出的是**可刷性**（hackability）；初赛 89.8% 步数逃到平底、随机基线 2/3 掉进 γ16 才是**实际被糊弄**（hacking）。AEvo 报告去掉 harness 后 3 次 run 有 2 次进入 reward hacking——与我们随机基线 2/3 数值一致，是"不设审计一定被糊弄"的跨域证据。

**评审（判据局 / 换名局）**：LLM 评审的不可靠性已被反复独立证实（Beel 等对 10 篇人写论文误拒 9 篇且漏掉最严重问题；AARRI-Bench 的伪造数据任务里 16 个配置仅 1 个看穿）；名字作为污染通道也有先例（PhysGym L4 匿名变量名、MLE-bench 抹掉赛事出处并得到**阴性**结果 8.5%→8.4%）。**我们唯一主张的是设计**：真名 / 匿名（M1–M7）/ 互换名三组配对，把"名字"隔离为因果通道。真名版把环带功率标可信 3/5、把 u/v 标可刷 4/5；匿名版降到 1/5 与 1/5；互换名后，穿着"环带功率"外衣的 u/v 数据仍被疑 4/5。阴性对照：残余流两版都被标可刷 5/5。病症的学名是 **authority borrowing**。**跨模型复核（E62）**：同一套题面、同样每条件 n=5，换到 `deepseek-v4-flash` 重跑一遍。核心效应逐位复现——真名下环带功率被判可信 **3/5**，匿名后降到 **1/5**，两个模型完全一致；换名局里穿着"环带功率"外衣的 u/v 数据被判可刷 4/5（pro）与 5/5（flash），方向一致；阴性对照（残余流两版都被判可刷）在两个模型上都稳定。**但有一半是模型依赖的**：真名下 u/v 被判可刷在 pro 上是 4/5、在 flash 上只有 2/5。因此可主张的只有前一半——**"有名字的头条指标更容易被信任"在两个模型上都成立**；而"有名字的候选指标更容易被怀疑"只在 pro 上明显。结论仍限定在同一家族的两个模型、每条件 n=5 之内，跨厂商复核（如 CellScientist 的 6 backbone × 3 prompt）仍未做。

**提议者（E43，初赛）**：30 轮（20 轮格式有效）0 通过；按穷举基率 1.33%，20 抽 0 中的概率 0.77——与随机无差别。承认先行：Agent 不会构造控制组已被 FIRE-Bench 在 30 任务 × 4 agent 上独立证明。也承认反例：在积木基已含答案或存在可执行外部锚时 Agent 确实能提出并被验证（PhysMiner 的 SGS 模型过 a posteriori LES）。**我们独有的是缺口的粒度**：0/20、基率 1.33%、P(0 中) = 0.77，缺口具体到"构造零真值子空间"这一步；4.8 进一步把这个缺口定位到"稳定性而非能力"；且我们坚持**可读的符号积木**形式，因为不可读的策略无法被 A1–A9 逐格审计。

## D-4.4 为什么 u/v 家族没有普适版本：机理全文（对应正文 4.4）

一把比值尺子要满足两件事：排得准的程度要求它的某一端被真信号钉住；抗糊弄的程度要求它换到平底不变好看。以下解释在 45° 检验后只剩**描述性地位**。区域 x 周期、y 陆墙：B 在 0°/90° 下看起来由几何主导——两种风向下平底的 u/v 都高于海山（配对中位数 2.64 vs 2.36；2.82 vs 2.56）——我们的解释是周期方向允许平底残留一支纬向流（**推断**：只有配对中位数，无平底流场剖面）；A 主要由真信号住在哪个分量决定（纬向风下 MITgcm 真值 |V|max 0.091 > |U|max 0.080，经向下互换——**单帧极值，惯性振荡下随相位旋转，属推断**）。两条件在纬向强迫下巧合落在同一对 u/v，经向下分家。

**45° 预注册检验（E55）反驳了其中两条**：P1 中（u/v 与 v/u 都没同时过两关）、**P2 被反驳**（u/v 抗糊弄的程度从 1.00 掉到 0.25，v/u 从 0.22 升到 0.82——抗糊弄的程度不是几何单独决定的）、**P3 被反驳**（u/v 在 45° 排得准的程度 −0.97，比 0° 还强）、P4 中。**我们的几何/分量解释只对了一半**，据此降为描述性陈述。

最粗的代理 deep_rms_800 在纬向/经向实例内排序 ρ = −0.963/−0.990，内潮对锚 −0.96，只是完全不抗糊弄（B=0）——**好排序器不等于好尺子**；此现象在自适应网格文献中已有先例（TrueError 不是性能理论上界，RL 有时超过它）。

其余家族：纬向∩经向的 88 把以 (v,w)、(w,w)、(temp,temp)、(u,w) 为主，它们在内潮全部未通过三轴报警判据。

## D-4.5 A9 静止态检验（E56）：详细设计与预注册逐条核对（对应正文 4.5）

Beckmann & Haidvogel（1993）的静止态海山检验是本领域评价 σ 坐标压力梯度误差的社区标准。我们按其设置重编无风二进制（`undef SEAMOUNT_WIND`，sha256 `00751585…`）、按 T = f(z) 逐点生成水平等密初值（`|T − f(z_r)|max = 0`，逐点验证）、u=v=ζ=0，跑 VISC2 七档 × 两地形 = 14 条。静止态下真值解析为零：任何非零流动都是纯误差。

结果（预注册 `7792b30e…`，P1/P2 命中、**P3 被反驳**）：
- **平底全档 `u_max = 0.0000`**——零真值通道的教科书级正对照。
- 陡海山 `u_max` 从 99.72 单调降到 18.79 cm/s（降 81%，ρ = −1.000，p=0.0004）。
- **A1 配对抗糊弄 = 0.000**：换到平底读数精确归零，**社区标准的那把尺子在这条路径上同样完全不抗糊弄**。
- P3 被反驳：我们预测同样的黏性档位会在风驱算例上毁掉真信号，实测技巧评分反而单调**上升**（−8.48 → −1.46，ρ = +1.000）。所以 BH93 尺子的毛病**不是"被糊弄过去"，而是"无判别力"**：它把伪流降 81% 报成改进，而真值说技巧评分**全程为负**——拧到物理上已荒谬的黏性上限，模式仍比"什么都不做的恒零模型"更差；且可见代理降 83% 而真实误差只降 49%，**夸大 1.69 倍**。

## D-4.6 无真值预测排得准的程度（E59）：详细设计、预注册原文与逐条核对（对应正文 4.6）

前五节的判据里藏着一个实用性问题：**排得准的程度 A 需要真值才能算，而真值在现实中往往拿不到**；真正能在无真值处执行的只有抗糊弄的程度 B 一类。既然已测得 ρ(A,B) = −0.674，说明无真值的 B 携带着关于 A 的信息，那就该正面问一句：**只用不需要真值的观测，能不能预测一把尺子有没有排得准的程度？**

预注册（sha256 `533c3062…`）写死了设定：候选空间与 E40 逐字相同，**纬向风环境训练、经向风环境测试**（跨环境泛化是唯一验收方式），七个特征全部不得触碰真值——配对抗糊弄、平底组噪声、海山组动态范围、地形敏感度、是否同分量、深度层级差、与已知旋钮 VISC2 的秩相关；模型只用一次拟合的逻辑回归，不调参、不做特征选择。

**结果（P1/P2/P4 命中，P3 未命中）**：
- 单特征里，抗糊弄的程度 B 的测试集 AUC = **0.2005**（远离 0.5，且方向为负——越抗糊弄越不可能有排得准的程度，与 4.1 的互斥结构一致）；与旋钮的秩相关 AUC = 0.6752；平底噪声 AUC = 0.4244。
- 七特征逻辑回归在**从未参与训练的经向风环境**上 AUC = **0.8706**。无真值特征对排得准的程度确有实质预测力。
- 但 P3（预测分最高的 204 个中，命中率至少是基率的 3 倍）**未命中**：实测 precision@204 = 0.0882，**低于**基率 0.280。

**这个矛盾我们查了三轮，前两个解释都被数据推翻，全部留档**（`E59_TRUTHFREE.json:posthoc_explanations_tested`）：
1. 假设"无真值特征只能预测判别力强度、预测不了方向"——**推翻**：在 \|A\|≥0.7 的 8538 个候选里预测方向的 AUC = 0.919，方向比强度（0.813）更好预测。
2. 假设"最高分那批是训练分布之外的外推失败"——**推翻**：top-204 的七个特征全部落在训练集 1–99 分位之内，0 个外推。
3. 真正的结构是**非单调**：按预测分等频分箱，命中率从 0.037 一路升到峰值 **0.8306**（score≈0.02807，n=1098），随后在最高分一箱回落到 **0.6906**；若只取最极端的 0.5%（77 个），命中率跌到 **0.052**。

**这是我们这项工作的主题在我们自己的工具上复现了一次**：我们造出一个用来预测"哪把尺子可信"的分数，它在中段确有判别力（峰值命中率 0.8306 vs 基率 0.280），可一旦把它推到极端，它就和被它审判的那些尺子一样开始骗人。可操作的读法因此是明确的——**用中段，不要用顶端**；而这条建议本身也只在本环境族内有依据。

图 4 给出这条曲线。就我们这项工作的定位而言，E59 把协议从"只能事后判定失效"往前推了一步：**在没有真值的地方，它能把 15376 个候选缩到一个判别力显著富集的中段区间**；但方向仍需真值确认，且预测器自身的极端区不可信——两条限制随结论一并列出，不单独存放。

## D-4.7 抗糊弄的程度与地形陡度（E60）：详细设计、预注册原文与逐条核对（对应正文 4.7）

E59 审计了我们造的预测器，本节审计**判据本身**。抗糊弄的程度 B 的定义是「同参数换到平底，读数不变好看」——可这个配对里"海山有多陡"是一个自由参数。**若 B 随陡度大幅漂移，那它和被它审判的那些代理指标就是同一个毛病**；报告此前也把"陡度 rx0 未变"列为适用边界。

预注册（sha256 `af8fe044…`）设定：取现成的四档陡度网格 rx0 = 0.200 / 0.441 / 0.599 / 0.694（42×42×13），每档配一个同尺寸、同最大深度的平底对照，初值按 T = f(z) 逐点重造；VISC2 七档 × 2 地形 × 4 陡度 = **56 条算例，全部完赛**。每档用与 E40 逐字相同的穷举器算全部 15376 个候选的 B（**只需配对，不需要 MITgcm 真值**）。

**结果（P2/P3 命中，P1/P4 未命中）**：
- **P1 被推翻，而且是朝有利方向**：我们赌任意两档之间「B≥0.9 的候选集合」的 Jaccard < 0.5，实测 **0.817–0.968**；B 的候选间秩相关 **0.734–0.953**。四档的通过比例几乎不动（44.4% / 44.6% / 44.4% / 44.6%）。**抗糊弄的程度在陡度轴上是稳健的。**
- **P2 命中**：深层残余流类（`u|d800|rms`）在全部四档陡度上 B = **0.000**——"完全不抗糊弄"是跨陡度成立的构造性结果，不是某一座海山的巧合。
- **P4 未命中，原因是我们预注册时写错了前提**：我们按 E56 静止态的直觉预测"平底 max\|u\| 应低于陡海山的 10%"，实测比值 0.157–0.741。但风驱设定下平底本就有约 14 cm/s 的**真实风生流**（非误差），零真值只对 PGE 分量成立。这不影响 B 的有效性（B 比较的是同一读数在两种地形下的相对大小，不要求平底为零），但预测写错了就是写错了，照实记下来。

**这个结果揭示出两关之间一个此前未被注意的不对称**（图 5）：
- **排得准的程度 A 换个强迫方向就崩**：同一把 u/v，0°→45°→90° 的 A 是 0.92 → 0.97 → **−0.17**（变号；对应的原始秩相关 ρ 是 −0.92 → −0.97 → +0.17）。
- **抗糊弄的程度 B 换个地形陡度纹丝不动**：Jaccard 0.82–0.97。

也就是说，**B 测的是尺子自身的结构性质（对地形稳健），A 测的是尺子与特定物理场景的匹配度（对强迫方向敏感）**。两者捕捉的不是同一层次的东西——这给"为什么必须同时要求两关"提供了一个此前没有的正当性论证，也把 §4.9 里"陡度 rx0 未变"这条边界从"未验证"升级为"已量化且稳健"。

**边界**：本节只在 42×42 的四档陡度内成立，与主环境的 48×48（rx0=0.766）跨尺寸不并入同一统计；陡度轴之外的层结尖锐度与垂向层数仍未变。

## D-4.8 Agent 与线性模型同信息条件对比（E61）：详细设计、预注册原文与逐条核对（对应正文 4.8）

E59 证明七个无真值特征可跨环境预测排得准的程度。我们这项工作此前反复承认"Agent 只是被测对象与对手，不是发现者"（E43 提议者 0/20），但那是一次**没有对照**的失败。本节把 Agent 放进与那个七参数逻辑回归**完全相同**的信息条件下，正面比一次。

预注册（sha256 `67d3ede0…`）设定：候选池取经向风环境（Agent 与逻辑回归都没在其上训练过）；每局展示 **40 个候选**（按 E59 预测分四分位分层抽样，各 10 个），每个只给七个无真值特征的数值，**不给真值、不给排得准的程度 A、不给 E59 的预测分**；任务是挑出 10 个"最可能与隐藏真值有强排序关系"的候选并说明理由；**8 局**独立抽样，单模型 `deepseek-v4-pro`。

**结果（P2 命中，P1 未命中，P3 部分推翻）**：

| 方法 | 8 局平均命中率 |
|---|---|
| 逻辑回归（七参数，E59 训练所得） | **0.675** |
| 低 B 启发式（只取抗糊弄的程度最低的十个） | 0.500 |
| Agent（deepseek-v4-pro） | 0.412 |
| 随机（每局 200 次重采样） | 0.283 |

- **P2 命中**：Agent 输给逻辑回归，8 局无一胜出（符号检验 p = 1.00）。它甚至输给"抗糊弄的程度最低的十个"这条**单特征**规则。
- **P1 未命中**：Agent 的 0.412 虽高于随机的 0.283，但 8 局符号检验 p = **0.1445**，**不显著**。按预注册纪律，我们不能声称 Agent 强于随机。
- **P3 部分推翻**：我们赌它会主要引用抗糊弄的程度并把方向用反。实测最常引用的是平底噪声、海山动态范围、与 VISC2 的秩相关（各 8/8），抗糊弄的程度只有 5/8；方向上它多数时候用**对**了（4 局说"抗糊弄低更好"，仅 1 局说"抗糊弄高更好"）。

**一个事后观察（非预注册，n 极小，只作探索性陈述）**：按 Agent 自述的抗糊弄的程度使用方向分组——说对方向的 3 局平均 **0.60**（逼近逻辑回归的 0.68），说反方向的 1 局 0.30，没说清或混合的 4 局 0.30（回到随机水平）。

**这给了"Agent 不是发现者"一个比 E43 精确得多的含义**：它**不是读不出规律**——8 局里有 3 局它明确说出了正确方向，那几局的成绩逼近线性模型；问题是**读出规律的过程不可重复**，另外 5 局它要么说反、要么说不清，成绩就掉回随机。而逻辑回归一旦拟合完，抗糊弄的程度的系数恒为 −2.57，方向每局都对。**稳定性，而不是能力，才是这里的瓶颈。**（图 6）

这与官方说法一致：一个非平凡的基线可能比复杂 Agent 更强，这是需要如实比较、而不是回避的结果。**边界**：单模型、n=8、单一任务形式、分组由正则从自述理由中抽取，全部为探索性观察，不作统计推断；换模型或换提示词都可能改变结论。
