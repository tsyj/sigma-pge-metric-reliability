【第1页】
Strathern 1997 说过："当一个指标成为目标，它就不再是一个好指标。"我们把它搬进海洋模式：把真值藏起来，给每一把尺子打分。

【第2页】
σ 坐标模式在陡地形会凭空长伪流：第一天全域最大流速，MITgcm 真值 9.24，ROMS 是 99.53 厘米每秒。但问题在后一层——评价它的每个读数，本身都是候选尺子。

【第3页】
四把尺子先过 R 列——现行大模型评审判据——全过。再过 A1 到 A9，全死。第九项 BH93 静止态检验：代理降 83%，真实误差只降 49%。对照行是隐藏真值，全过——协议不是在杀一切。

【第4页】
风驱一万五千多个候选，排序力对抗刷率，Spearman 是 −0.674；两关同过 204 个，比独立期望贫化 10.6 倍；乌托邦角 (1,1) 是空的。会排序的和抗刷的，是两拨尺子。

【第5页】
四条盖章预测被数据反驳。还亲手判死了自家论文头条——环带辐射功率：A3 只改盒宽，摆 7.24 倍；A4 修一行时钟，4.58 变 7.89；500 公里口径，0.525 回到 0.942。它量的是域共振，不是辐射。E58 三值化后，协议能可靠判死，不能可靠认证。

【第6页】
我们交的不是尺子，是给尺子打分的协议——手册里的"元环境 / 评测范式"类，已在 σ 伪流上跑通。出题人说："一次完整而诚实的失败，比十张无法复查的漂亮结果图更有价值。"我们交的，就是这样一次失败。谢谢。
