# 谁来给尺子打分：σ 坐标伪流环境中的代理指标可靠性探索
## 复赛《科学发现与环境定义报告》 v4（方案 B 骨架：五节标题不动，换主语）

> 一句话：尺子的可靠性不是标量的性质，是审计协议的性质。我们把真值藏起来，让每把尺子都能被打分——作者自己的论文头条、有名字的大模型评审、两万选一的穷举冠军，都在"看起来合理"上栽了；唯一活到最后的 u/v 比值，在审计下被一路收窄成一把单向、同域、相对排序器，换到第三种强迫也死了。

# 第一问 · 科学问题与发现目标

σ（地形跟随）坐标海洋模式在陡地形上会凭空长出伪流，这一点初赛已经用独立真值量化（同一座海山，真值 9.2 cm/s，σ 坐标 100 cm/s；附录 A）。但真正的问题在后一层：评价"伪流治理好不好"的每一个可见读数——深层流速、残余流、辐射功率——本身都是一把候选尺子，而真值平时是拿不到的。所以我们研究的不是"怎么治伪流"，是**"谁来给尺子打分"**。

初赛在一个算例上回答了"尺子会被怎样刷穿"：三条路径，一个机制（让一切变小），并从 15376 个候选里穷举出一把抗刷的比值尺子 u/v。复赛的发现目标是把这个问题问到底：**一把在一个环境里抗刷的尺子，换环境、换相位、换盒宽、换强迫方向之后，还剩什么？** 我们的核心科学声明是一句负结果加一句正结果：

- 负：在三种强迫（纬向风、经向风、M2 内潮）、共约三万五千个候选指标里，**没有任何一个标量尺子活过全部审计**；两环境交集里的 13 把，换到第三种强迫全部失效。
- 正：失效的方式是可预测、可解释、可复算的——每一格都能追到一条审计、一个数、一个文件。可靠性是这套审计协议的性质，不是某个标量的性质。

# 第二问 · Environment / Benchmark 定义

我们把环境写成四元组 **(K, V, H, A)**：可拧的旋钮 K、Agent 看得见的读数 V、藏起来的判分 H、以及给尺子打分的审计算子集 A。前三项是初赛就有的（附录 A §2），复赛把 A 提成了一等公民。

**K（固定部分与可探索部分）**：三个物理驱动共用一套接口——风驱海山（48×48×13，2 分钟一条）、M2 内潮（84 km 盒，9 分钟一条）、经向风（风驱的 90° 转向版，补丁 20 行、重编译，MITgcm 真值同步转向并精确镜像）。旋钮：黏性/扩散四档（风驱）、双谐波黏性、B 样条节点距与强度、参考态修正（内潮）、地形三选一、积分长短。求解器二进制、编译选项、网格、初值全部固定并留指纹。

**V（可见读数）**：流速幅值类（最大/均方根/深层）、残余流幅值、u/v 与 v/u 比值、正压振幅、谱尾占比、层结漂移、环带波功率。全部由固定代码算出，语言模型只挑下一步。

**H（隐藏判分，三种形态）**：风驱——MITgcm z 坐标独立解（双侧：既罚伪流也罚失真）；内潮——500 km 大盒上先盖章后验证的逐垂向模态远场功率（**单侧**：只量"治理伤了多少波"，零治理臂恒为最优，这一点必须明写，它决定了 4.2 里两把尺子的排名反转）；两者共用一条零真值通道——平底海上伪流按构造为零、内潮辐射恒为零。

**A（审计算子，本作品的核心贡献）**——每个算子回答一个问题，标注机时成本与它已经杀掉的尺子：

| 算子 | 问什么 | 成本 | 已杀掉/收窄 |
|---|---|---|---|
| A1 配对抗刷 | 同参数换到平底，读数会不会变好看 | 零机时（32/28 对） | 残余流类（抗刷率 0.000） |
| A2 零真值通道 | 真值恒为零的地方读数是不是零 | 零机时 | u/v 在平底发散（分母→0） |
| A3 盒宽扰动 | 只改盒子宽度，读数动多少 | 2.8 h/条（在档） | 环带功率摆 7.24× |
| A4 时钟/相位扰动 | 改一行初值时钟或 ±T/8，读数动多少 | 9 min/条 | 环带功率 4.58→7.89；末帧类读数 ±30–66% |
| A5 盖章预测 | 先写预测再跑，中不中 | 零机时 | u/v "会失效"的预测被反驳；"守门会退化"落空 |
| A6 跨环境（第三强迫） | 换驱动方向，还过不过 | 56 条×2 min | 两环境交集 13 把全部失效 |
| A7 匿名/换名 | 把名字摘掉或互换，评审的判断变不变 | ¥5 | 有名字时坏尺子被信、好尺子被疑 |
| A8 真值锚 | 与隐藏真值的秩相关 | 零机时 | 暴露内潮真值单侧：残余流比 u/v 更贴锚 |

**可比性契约与一处主动申报**：所有读数只在同初值相位、同窗口、同口径内比较；跨相位用窗均值版。可见的环带功率在节点距轴上与隐藏模态损伤同序（ρ=−1.0）——藏起来的是定量判分和物理含义，不是方向信息；它是环境里故意保留的一个"方向对、含义错"的诱饵读数。

# 第三问 · Agent 如何完成发现

Agent 在这个环境里有三个角色，每个角色一段、一个数、一个诚实的边界。

**对手（陷阱局）**：目标一句话"把深层残余流降到最低"，六轮预算，环境按它的配置真跑模式。它靠自设的"功率须为正"守门躲开了功率反向的最深坑，但终选方案深层残余流 −47%、环带功率只剩修正臂的 30%；全程可见的 u/v 从 2.54 升到 3.46 一路报警，它没有用；交卷时它写的顾虑说中了要害。**换成中性措辞**（"弄清楚哪些读数可信，推荐一个物理上最可信的配置"）再跑一遍：终选配置一模一样，并把 u/v 标为"误导"、把环带功率标为"可信"——不是措辞的问题，是尺子的问题。同预算随机基线三席里两席掉进 γ×16（功率 −8.9 MW），比 Agent 掉得更深。（n=2 局 + 3 席随机，单模型，明写。）

**评审（判据局 / 换名局）**：把 15 个算例的参数与 7 个可见指标交给 DeepSeek 评审。有名字时，它把环带功率标"可信"、把 u/v 标"可刷"；摘掉名字（M1–M7）两处判断翻转、翻对。复赛补做了真名 / 匿名 / 互换名各 5 次独立调用（E54，结果表见附录 B），把"名字是污染源"从 1 对 1 的轶事变成有对照的读数：〔E54 k/5 数字回填〕。

**提议者（E43，初赛）**：让它用积木自己提判据，30 轮 0 通过；按穷举基率（204/15376=1.33%）30 抽 0 中的概率约 0.67——与随机无差别。它会讲"无量纲比值抗缩放"的道理，找不到零真值子空间。**结论：目前 Agent 是对手和被试，不是发现者**；缺口具体到"构造零真值子空间"这一步。把出题者与刷分者做成对抗式双 Agent 环境（ARENA 规格见附录 C）是我们写明的下一步，不是本次成果。

工作流本身钉死：预注册（sha256 盖章，含一条被反驳的预测）→ 扫描（20+7+3+2+56 条，全部一次完赛、无筛选、md5 审计、健康门）→ 逐条对账 → 审计。每一步的轨迹与产物都在仓库里。

# 第四问 · 发现结果与验证

**图 1（kill board）：四把尺子 × 八个审计算子。**行是四把有代表性的尺子——我们自己论文头条的环带波功率、最常用的深层残余流代理、内潮穷举的三轴满分冠军（它其实是 ≈4 °C 的深水温度本身）、风驱穷举冠军 u/v 比值；列是 A1–A8；每格一个判定、一个数、一个出处文件，`python scorecard.py` 从 analysis/*.json 一键重生成。**没有一行全绿。**

## 4.1 自家头条之死（科学更正）

环带"相干辐射功率"上过我们论文头条："最优方案只保留 11.1% 的相干辐射"。A3 只改盒宽，它摆 7.24 倍而正压响应只差 1.5%；A4 修一行初值时钟，4.58 变 7.89 MW；换到 500 km 干净口径，"物理最差 11%"大半消失（0.52 回到 0.94）。它量的是域共振，不是辐射。本报告把它降为环境内"游戏分数"；论文将作更正。研究尺子的人自己栽在尺子上——我们把这当成这个问题真实存在的最好证明。

## 4.2 幸存者被一路收窄（u/v 比值）

预注册赌它在内潮环境失效，数据反驳了：三轴单调报警（ρ=1.0/0.976/0.893，精确置换 p=0.017/0.0004/0.012）。但接下来每一条审计都削掉它一块：
- A8：内潮隐藏真值是单侧的，在 5 个有锚的臂上残余流对真值 ρ=+0.90、u/v 只有 −0.70——两把尺子 22 臂上共线 −0.923，几乎是同一条信息取相反符号。所谓"配对判据"因此只是同一条轴上加一道过度治理的截断门（E53：门内取最强治理，挑中 m2），不是两条独立证据。
- A2：平底纯纬向振荡时分母趋零，读数发散。
- A4：末帧版对相位摆 ±30–66%，窗均值版 4%；序保持——它可信的形态只剩"同域、同口径、相对排序器"。
- A3：500 km 上绝对值 2.4→17，序保持。
- **A6（E52，主结果）**：转成经向风，u/v 排序力从 −0.92 掉到 +0.17；镜像 v/u 排序回来（−0.92）但抗刷率只有 0.11。三重交集 0/15376。机理见下。

## 4.3 为什么没有普适的标量尺子（E52 机理）

一把比值尺子要同时满足两件独立的事：排序力（A）要求它的某一端被真信号钉住；抗刷分（B）要求它换到平底不变好看。区域是 x 周期、y 陆墙：B 由区域几何决定——周期方向允许平底残留一支纬向急流，所以 u/v 在平底总比海山高（两种风向下平底≥海山 100%/89%）；A 由真信号住在哪个分量决定——纬向风的表层真信号在 v（埃克曼右偏），经向风把它搬到 u。两条件在纬向强迫下巧合落在同一对 u/v，经向下分了家，没有任何一个比值同时满足。最粗的代理 deep_rms_800 在三种强迫下实例内排序都是 ρ≈−0.99，只是完全不抗刷分——好排序器不等于好尺子，两条要求彼此独立。

## 4.4 统计地板

三轴单调的显著性（联合 p≈4.5×10⁻⁸）要和它的基率一起读：内潮 19600 候选里 13.1% 都过三轴报警判据——单环境单调是低门槛；起筛选作用的是跨环境交集（0.066%）与第三环境否决（0）。经向风判据 A 只有 22 条带真值的算例，纬向限到同口径子集（52 条）复核结论不变。所有 ρ 均附 n 与精确置换 p（E44_VERDICT_v2.json）。

## 4.5 稳定性、人工干预与 false positive

全部 88 条扫描算例一次完赛、无筛选无重跑，健康门全绿；同配置重跑逐位一致。陷阱局第一版因环境侧 Fortran 字面量 bug 作废（只影响 Agent 下单路径，扫描不受影响；轨迹与声明随包）。已知 false positive：84 km 模态类读数只做方向判读；单模型 Agent 实验 n=2；E52 的第三环境与前两者共用海山与网格，只换强迫方向与真值。
